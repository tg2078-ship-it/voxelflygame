## 원본 품질과 최적화

실제로 참조되는 모든 삼각형과 정점의 POSITION·NORMAL·COLOR·UV·모프 속성을 보존합니다. 정점 참조 순서를 바꾸고 참조되지 않는 저장 공간을 제거하며, 모든 원본 삼각형의 존재와 방향을 대조합니다. 런타임 변환에서 추가 위치 양자화를 하지 않습니다. 원본에 이미 적용된 16비트 좌표의 오차는 `sourcePositionErrorM`, 이번 처리로 추가한 오차는 `addedPositionErrorM: 0`으로 구분합니다.

원본의 26,614,206 / 4,044,568 / 1,445,084개 삼각형을 LOD0 / LOD1 / LOD2에 각각 유지합니다. 네이티브 부모 계층·피벗·TRS·키프레임·수동 조종면·기어·자동 재생 목록을 유지합니다. 데이터 저장 위치와 accessor 참조 번호만 바꿉니다.

Meshopt의 무손실 속성 인코딩과 표준 gzip을 사용합니다. 반복된 원본 이미지 11,655개는 이미지 자체를 재압축하지 않고 SHA-256 기반 공유 파일 59개로 분리합니다. PBR 재질, 텍스처 인덱스, 샘플러, 색 공간과 UV 연결을 보존합니다. 원본의 실제 모델 렌더 JPEG 403개를 포함합니다. 프리뷰는 원본 에셋 렌더이며 게임 플레이 캡처를 의미하지 않습니다.

## 충돌과 움직임

Edition8의 구조 박스 436,671개와 별도로 기록된 세부 솔리드 72,776개를 모두 처리합니다. 세부 솔리드는 박스 70,546개, 볼록 형상 1,708개, 원기둥 522개입니다. 움직이는 세부 형상의 `world_rest` 좌표를 실제 네이티브 피벗의 로컬 좌표로 바꿔 동작에 결합합니다.

최종 물리 데이터는 박스 **507,217개**, 삼각형 **79,284개**입니다. 새 11종의 원본 비볼록 단순 충돌 표면은 문·아치의 빈 공간과 네이티브 계층을 유지합니다. 나머지 모델은 구조 박스와 세부 삼각형을 함께 사용합니다. 총 125종에 삼각형 물리가 있습니다. 정밀 시각 LOD0를 거대한 단일 AABB로 대체하지 않습니다.

`bounds`와 `lodBounds`는 실제로 참조된 시각 정점의 정지 상태 범위입니다. 원본 accessor의 미참조 정점 때문에 과도하게 커진 135개 LOD 범위를 교정했습니다. `motionBounds`는 실제 Hero 범위와 모든 정적·동적 물리 범위의 합집합입니다. 구획 배치와 안전 경로 예약에는 `motionBounds`를, 지면 접지에는 실제 정지 상태의 하단과 제공된 지상 자세를 사용합니다.

동적 범위는 전체 부모 계층의 이동·스케일 키 범위와 회전축의 반경을 이용한 보수적 경계입니다. 회전 위상은 렌더와 물리에서 같은 시간을 사용해야 합니다. 모든 모델이 동시에 같은 위상으로 움직일 필요는 없지만, 각 인스턴스의 위상은 시각과 물리가 일치해야 합니다.

## 이번 통합의 검증

- 1,209개 런타임 GLB를 실제 Three.js GLTFLoader와 MeshoptDecoder로 임포트했습니다.
- 원본 이미지 11,655개를 내용 해시로 대조하고 공유 이미지 59개와 프리뷰 JPEG 403개를 실제 CPU 이미지 디코더로 열었습니다.
- 네이티브 리그 203종, 클립 775개를 보존했습니다. 실제 시각 모델과 물리 리그의 행렬을 10,260회 대조한 최대 오차는 0입니다.
- 동적 충돌 모서리 3,034,008개가 실제 네이티브 포즈에서 보수 경계 안에 들어가는지 검사했습니다. 부동소수점 잔차는 8.9e-16 m 이하입니다.
- 시각 범위를 실제 GLTF 정점과 대조한 오차는 0입니다.
- 모든 박스·삼각형의 BVH leaf 참조를 전수 검사했습니다. 중복과 누락이 없으며 독립 쿼리 17,232개가 통과했습니다.

최신 수치와 추가 검증 결과는 `docs/validation/asset-edition9-*.json`에 있습니다. 위 검사는 CPU에서 수행한 데이터·임포트·수학적 포즈 검증입니다. 실제 GPU 화면 품질이나 PC·모바일 FPS를 측정했다는 의미는 아닙니다.

## 재현

`scripts/prepare-edition9-models.py`가 원본 ZIP을 데이터로 읽어 카탈로그·원본 프리뷰·물리·시각 모델을 생성합니다. ZIP 안의 코드는 실행하지 않습니다. `scripts/encode-edition9-lossless.mjs`가 실제 round-trip 검증을 포함한 런타임 인코딩을 담당합니다. `scripts/audit-edition9-runtime.mjs`, `scripts/audit-edition9-physics.py`가 독립 임포트·포즈·원본 레코드·BVH 검사를 수행합니다.

원본 README, 통합 안내, 라이선스, 제작자 제공 검증 기록은 `public/models/source-notices`에 보존합니다. 제작자의 기존 검증과 이번 게임 통합에서 직접 수행한 검증은 구분합니다.
