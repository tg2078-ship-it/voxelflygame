# VOXEL AIRRUN 4.4 — 풍경, 원본 움직임, 비행 표현

## 구현한 변경

- 자연물을 지형에 맞는 군집으로 배치합니다. 해안에서는 육지와 섬의 높이를 확인하고 테마에 맞는 원본을 사용합니다. 회전한 모델 폭까지 고려해 조종 구역 밖에 배치하고 밑면을 지면에 접촉시킵니다. 품질별 배치 개수 상한은 유지합니다.
- 구름의 일부 복셀만 추출하던 방식을 완전한 덩어리 생성으로 바꿨습니다. 모든 품질에서 32개 구름을 유지하며 각 덩어리가 함께 순환합니다. 노을·일출·밤 색을 연속 보간합니다. 형상이 있는 복셀 구름이며 볼류메트릭 레이마칭은 아닙니다.
- 원본 GLB에서 같은 움직임 축의 불투명 부품을 재질별로 합칩니다. 원본 계층·클립·UV·정점 색·PBR 재질은 보존합니다. 개별 애니메이션 부품·스킨·모프·투명 부품·반사 변환 등은 병합에서 제외합니다. 기존 동일 부품 인스턴싱과 함께 작동하며 비직교 변환은 원본 렌더러로 되돌립니다.
- 준비된 CPU 장면의 그리기 비용을 여러 애니메이션 시점에서 계산해 표시 거리와 예산에 반영합니다. 플레이어 접근 전에 준비하고 표시 경계에 완충 구간을 둡니다. 먼 모델을 항상 애니메이션하는 방식은 아니며 거리·개수·그리기 예산은 유지합니다.
- 근거리 원본 움직임을 즉시 표시하고 최적화 준비가 끝나면 이어서 적용합니다. 준비를 기다리며 가까운 움직이는 장애물이 잠깐 정지할 수 있던 회귀를 수정했습니다. LOD 변경 시 이전 LOD의 비용이 새 예산을 덮어쓰지 않게 했습니다.
- 준비 중 원본 캐시를 유지하고 마지막 참조가 해제되면 병합 형상을 함께 정리합니다. 장면 전환 뒤 도착한 비동기 인스턴스도 해제합니다.
- 부스트 날개 궤적은 초당 60회 간격으로 보간해 생성하고 3초에 걸쳐 소멸합니다. 30·60·144 FPS 입력에서 길이와 경로가 같도록 수정했습니다. 표시용 비행 위치를 비·구름·수면·전조등에 공유하고 전조등은 비행 방향을 따라갑니다.
- 카메라에 작은 선회 기울기와 상승·하강 선행 시선을 추가했습니다. 모션 줄이기 설정을 적용하며 E 연출과 충돌하지 않게 했습니다. 충돌 흔들림은 비행 시간에 연결했습니다.
- 다음 통과 지점을 실제 카메라 3D 좌표에 투영하는 작은 표시를 추가했습니다. 너무 가까운 지점·화면 밖 지점·E 연출 중에는 숨깁니다. 기존 비행 정보와 키보드·터치 조작을 유지합니다.
- 테마 사전 썸네일은 다운로드뿐 아니라 애니메이션·지형·정적 모델 배치의 완료도 기다립니다. 새 준비 작업이 남아 있는데 촬영을 시도해 실패하던 문제를 수정했습니다.
- 표시 버전과 실제 장면 썸네일 캐시를 4.4로 갱신합니다. 원본 모델 파일 버전은 불필요하게 바꾸지 않습니다.

## 유지한 동작

4.3의 HIGH·125% 기본 선명도, MSAA/SMAA 지원 분기, 모델 세부 단계, 조명·안개·수면 색 공유를 유지합니다. 4.2의 연속 스트리밍, 다음 테마 사전 준비, 보이지 않는 장애물 충돌 방지도 유지합니다. 좌우 범위는 28m, 높이 상한은 52m입니다. 기체·재화·기록·퀘스트 저장은 유지합니다.

기존 403개 원본과 4개 보조 모델의 배치·렌더링 개선입니다. 새 모델 팩으로 교체한 것이 아닙니다. 테마별 원본 카탈로그와 순환 배치 검사를 유지하며 테마마다 일률적으로 39개라고 표시하지 않습니다.

## 검증

26종 회귀 검사, 타입 검사, 배포용 빌드가 통과했습니다. 썸네일 준비와 근거리 애니메이션 지연을 수정한 뒤 실패한 검사부터 이어서 실행했습니다. 영향을 받는 썸네일·30분 자원 해제 검사는 수정 후 다시 통과했습니다. 최초 실패와 수정 후 기록은 verification-4.4.json 및 verification-4.4.txt에 보존합니다.

새 장면 검사는 523,576개 조건, 202개 모델·LOD 사례와 정점 표본 90,960개를 확인했습니다. 최대 위치 차이는 약 0.00000065, 법선 차이는 약 0.000000027입니다. 원본의 잠재 그리기 개수 합계는 6,080, 기존 인스턴싱과 새 병합을 함께 적용한 결과는 4,790입니다. 이는 이전 버전 대비 개선율이 아닙니다. 품질 예산 650·900·2,600·5,200에서 구름 복셀은 645·886·2,578·5,170개이며 각 설정에서 32개 구름의 연결성을 확인했습니다.

HIGH·시드 44171의 6초 CPU 장면 표본입니다. 모든 장면의 비용을 대표하지 않습니다. CPU 시간은 다른 검사와 동시 실행되어 속도 비교에서 제외합니다.

| --- | ---: | ---: | ---: |
| 해안 | 599 | 2,228,154 | 48.09 MiB |
| 도시 | 527 | 2,204,024 | 50.86 MiB |

그리기 수치는 프러스텀·그림자·후처리를 포함한 실제 GPU 측정이 아닙니다. 작업 환경에 지원되는 브라우저 제어 도구가 없어 실제 WebGL 화면·모바일 레이아웃·기기 FPS를 확인하지 못했습니다. CPU·SSR·타입·빌드 통과는 실제 기기의 시각적 완성도와 재미를 보증하지 않습니다.
