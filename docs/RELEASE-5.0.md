# VOXEL AIRRUN 5.0 · Edition12

업로드된 `VOXEL-AIRRUN-403-Edition12-AllModels.tar.xz.bin`의 실제 XZ/TAR 바이트에서 403종을 가져왔습니다. 원본 SHA-256은 `5cd471e1c05e7ecf91229dc2d73e3b5add9e06f6365e47d609b6e3f6a4e75371`입니다.

- 403종, 시각 LOD 4단계 1,612개를 교체했습니다. 보조 교통 모델 4종은 유지합니다.
- 최고 단계에서 움직이는 모델 271종 / 클립 891개입니다. 제공 팩 자체의 LOD1은 269종 / 889개, LOD2·3은 265종 / 884개입니다. 모든 LOD의 동작 수가 같다고 간주하지 않습니다.
- 원본의 위치·법선·UV, 스킨 가중치·관절·바인드 행렬, 모프, 애니메이션, 삼각형·방향, 재질 맵 바이트를 유지합니다. 새 위치 양자화나 디테일 제거는 적용하지 않았습니다.

- 4개의 공유 재질 이미지를 모델마다 반복 해독하지 않도록 공유합니다. 현재 모델을 보호하는 참조 수와 별도로 사용하지 않는 지오메트리의 용량을 제한합니다. 이 한도는 전체 브라우저 RAM/GPU 메모리의 상한을 뜻하지 않습니다.
- 원거리 인스턴싱에서 스킨 메시를 빠뜨리던 경로를 고쳤습니다. 스킨·모프가 적용된 형상과 법선을 준비하고, 가까운 모델은 원래 클립을 재생합니다.
- 원본 충돌 GLB 403종의 2,702,604개 삼각형을 별도 BVH 자료로 사용합니다. 장식 바람은 비충돌입니다. 배너의 원래 모프 충돌은 시간에 따라 갱신합니다.
- 고정 충돌면과 미래 동작의 보수적 경계를 반복해서 변환하던 계산을 재사용하고, 안전하게 제외할 수 있는 삼각형을 먼저 거릅니다. 실제 움직이는 충돌면은 해당 시점의 관절을 사용합니다.
- 기체 도색은 새 atlas의 페인트 영역에만 적용하며 금속·유리·고무·등화는 보존합니다.

- 상세 모델 다운로드와 기본 비행 모델의 다운로드 자리를 분리했습니다. 비행 중 상세 교체가 전체 출발 로딩으로 돌아가는 분기는 추가하지 않았습니다.

## 배포 상세 단계

소스의 `public/models`에는 제공된 403종의 네이티브 LOD 4단계 전체를 보존합니다. 배포 서비스는 SDK의 512MiB 파일 전달 제한 외에 **256MiB 아카이브 입력 제한**을 적용하므로, 정식 빌드의 `prepare-model-delivery.mjs`가 배포용 자료를 선택합니다.

403종, 움직이는 모델 271종과 891개 클립, 403개 원래 충돌 자료, 원거리 LOD2·3을 모두 제공합니다. 기체 22종 전부와 주요 랜드마크는 원래 LOD0을 사용하고, 나머지 환경 모델은 제공 팩의 LOD1을 근거리 최고 단계로 사용합니다. LOD0에만 있는 두 해안 모델의 바람 동작도 보존합니다. 배포용 catalog는 실제 파일·형상·동작·비용·경계를 가리키며, 상세창은 실제 네이티브 LOD 번호를 표시합니다. 선택된 모델별 단계는 `docs/validation/edition12-delivery.json`에 기록합니다.

이 구성은 모든 환경 모델에 LOD0을 제공하는 배포가 아닙니다. 로컬 실행은 소스에 보존된 전체 LOD0을 사용할 수 있습니다.

## 확인한 범위

소스의 전체 1,620개 GLB(Edition12 1,612개 + 보조 교통 8개)를 Three.js GLTFLoader로 해독했습니다. 403종의 스킨 26종·모프 115종을 포함해 변형·복제·원거리 형상·공유 재질 수명 검사를 통과했습니다.

또한 제공된 충돌 GLB를 별도로 Three.js로 읽고 움직여, 403종 / 775개 원래 충돌 클립 / 204,508개 정점 시점 표본을 게임용 CPU 관절·표면과 비교했습니다. 최대 위치 차이는 약 `2.23e-16 m`였습니다. 이것은 충돌 자료의 변환 검사이며 시각 모델과 충돌 모델이 장식까지 동일하다는 뜻이 아닙니다.

192초 연속 비행 검사에서 출발 로딩 재진입은 0회였습니다. 44개 테마·시드·기체 조합에서 배정된 모델 전체의 생성과 카메라 범위를 검사했고, 22종 기체의 레벨별 66개 조종 검사는 240초까지 통과했습니다. 30분 분량의 월드 생성·자원 해제 검사도 통과했습니다.

E 경로 352개와 고속 시작 216개가 모두 충돌 및 종료 후 통과 공간 검사를 통과했습니다. 먼저 제안 곡선 전체를 같은 정밀 충돌 기준으로 검증하고, 실패할 때만 기존 탐색을 수행합니다. 도심에서는 열린 상승 경로와 지연 상승도 검증합니다. 원래 원거리 경계·회전 중 기체 크기·15초 지속 시간·종료 후 3초의 정상 조종 범위를 유지합니다.

동일한 한국 도심/틸트로터 시작점의 CPU 경로 준비는 앞선 측정 약 28.1초에서 수정 후 약 0.112초였습니다. 전체 352개 측정은 평균 약 11.8ms, 최대 약 2,692ms였습니다. 이 수치는 이번 실행 환경의 CPU 측정이며 실기기 지연이나 GPU FPS를 보장하지 않습니다.

28개 소스 검사 세트와 타입 검사가 통과했습니다. 별도로 실제 배포용 catalog와 파일에서 논리 LOD 1,620개 참조(물리 GLB 1,282개)를 모두 해독하고, 스킨·모프·복제와 192초 연속 비행을 재검사했습니다. 배포 구성의 최고 상세는 LOD0 65종(기체 22종 + 환경 43종) / LOD1 338종입니다. 새 모델별 동작·형상, 원본 충돌 GLB와의 독립 비교 외에 충돌 가속 결과를 모든 원본 표면을 직접 방문하는 계산과 1,512개 사례에서 대조했습니다. 접촉 시간 차이는 최대 약 `1.91e-14`였습니다. 상세 결과는 `verification-5.0.json`에 있습니다.

## 확인하지 못한 범위

미리보기 연결 실패 후 중단된 개발 서버의 잠금 파일을 정리해 재시작했으나, 클라우드 브라우저 관찰은 보안 정책으로 차단됐습니다. 정책을 우회하는 브라우저 경로는 사용하지 않았습니다. 실제 WebGL 화면, 실기기 FPS, 터치 체감, 체감 재미는 직접 검증하지 못했습니다. 자동 검사 결과를 실제 플레이나 일정 FPS 보장으로 해석할 수 없습니다.
