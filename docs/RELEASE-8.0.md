# VOXEL AIRRUN 8.0 — 완주할 목표가 있는 비행

7.0의 원본 콘텐츠와 저장을 이어서, 짧은 출격의 시작·고조·완주, 선택한 비행 목표, 같은 항로 재도전과 개인 고스트를 연결했습니다. 외부 사이트 게시가 아닌 실행 가능한 소스 업데이트입니다. 유료 출시 품질과 사람의 재미 평가는 자동 검사 결과만으로 판정하지 않습니다.

## 같은 항로에서 내 비행을 넘어서기

이전 생성기는 같은 시드라도 실제 가속·감속과 생성 시각에 따라 간격과 테마가 달라질 수 있었습니다. 출격 모드는 기체·강화 단계·난이도로 고정된 속도 기준과 거리 기반 순항 시계로 구조물을 생성하도록 바꿨습니다. 결과 화면의 **같은 항로 재도전**은 시드·기체·강화 단계·난이도·선택 목표를 유지합니다. 보유 기체를 나중에 강화해도 재도전은 이전 비행의 강화 단계로 맞추며, **새 항로**는 현재 보유 강화 단계를 사용합니다.

E 없이 정상 완주한 비행은 반 초 간격, 최대 400개 위치 표본으로 로컬에 기록합니다. 같은 조건의 최고 점수 비행이 있을 때만 반투명 와이어 기체와 실제 비행 시간 기준 앞섬/뒤처짐 거리를 표시합니다. 다른 기체·강화·난이도·목표 또는 E 사용 기록을 동일 조건의 고스트처럼 보여주지 않습니다. 서버 전송은 없습니다. 기록은 기존 20개 이내로 제한하면서 현재 재도전 중인 최고 고스트 한 개를 보존합니다.

## 플레이 스타일을 고르는 목표

출격 전에 정밀 통과, 수동 가속 거리, 실제 근접·협문 통과 중 하나를 선택합니다. 선택한 목표는 HUD의 주요 목표 카드로 표시합니다. 기존 즉석 작전은 계속 진행되고 점수와 결과에 반영됩니다.

세 단계의 실제 달성 보상은 **150 → 300 → 600점**, 합계 1,050점입니다. 목표치는 기체 속도와 난이도에 맞춰 정해지며, 화면을 다시 읽거나 저장해도 보상을 재지급하지 않습니다. 선택 목표·완주·작전·정밀·플로우 점수는 결과에서 합계가 맞게 표시합니다.

## 3분 출격

격납고에서 **3분 출격**을 선택합니다. 기존 무한 항로와 데일리도 그대로 사용할 수 있습니다. 비행은 처음부터 기존 시드 기반 절차 생성기를 사용합니다.

| 수동 비행 시간 | 단계 | 절차 생성 간격 |
|---|---|---|
| 0–25초 | 출격 항로 | 기본의 1.20배 |
| 25–70초 | 흐름 연결 | 1.08배 |
| 70–90초 | 재정비 구간 | 1.45배 |
| 90–155초 | 최종 도전 | 선택 난이도의 기본 간격 |
| 155–180초 | 귀환 항로 | 1.25배 |

위 단계 간격은 거리로 계산한 고정 순항 시계를 기준으로 항로에 적용합니다. HUD의 완주 시계는 실제 수동 비행 시간입니다. 가속하면 항로의 다음 구간에 먼저 도달할 수 있지만 구조물은 같은 위치에 남습니다. 고속·낮은 기동성에서 필요한 이동 여유와 기존 충돌 형상 검증을 유지합니다. 재정비 구간은 장애물 간 여유가 커지는 구간이며 무적 시간이 아닙니다.

180초의 수동 비행을 마치면 자동으로 결과 화면으로 이동하고 **1,200점**을 한 번 지급합니다. 미정산 플로우도 확보합니다. 일시정지와 E 연출은 완주 시계에 포함되지 않으며, 중도 종료·추락·미완주 체크포인트 복구에는 완주 보너스가 없습니다. 점수 배율 아이템으로 고정 완주 보너스가 다시 곱해지지 않습니다.

출격 기록은 난이도·기체·E 사용 여부에 따라 별도로 저장합니다. 기존 무한/데일리 기록을 덮어쓰지 않으며 코인·도전·성장·발견은 기존 정산 규칙과 연결됩니다. 결과 화면은 완주와 중도 종료를 구분하고, 보너스 내역 합계가 실제 총점과 일치합니다. 같은 항로 재도전과 새로운 항로 출격을 각각 선택할 수 있습니다.

## 실제 형상을 확인한 두 경로

조건을 충족하는 구간에는 기본 경로와 더 좁은 정밀 경로를 함께 표시합니다. 정밀 경로를 통과하면 **미정산 플로우 90점**이 추가됩니다. F 또는 화면의 확정 버튼으로 확보할 수 있으며, 기존 피격·단절·추락의 소실 규칙이 적용됩니다. ×2 효과는 통과 순간에 반영하고 이후 확정 때 다시 곱하지 않습니다.

선택지는 단순히 링의 좌표가 있다는 이유로 만들지 않습니다. 원본 충돌 프록시를 이용해 두 경로의 접근·통과·복귀, 지면 높이, 기체 폭, 최대 가속과 터보를 고려한 이동 시간을 검사합니다. 불확실하거나 움직이는 형상이 경로에 걸리면 선택지를 표시하지 않습니다. 기존 위험 링 전체가 안전성을 보증받는다는 뜻은 아닙니다.

경로 하나는 한 번만 적립되고 E 자동 비행은 이 보너스를 만들지 않습니다. 추가 적립을 별도의 정밀 통과나 연속 행동으로 중복 집계하지 않습니다. 화면 표식은 두 경로의 실제 월드 좌표를 투영합니다. 전방 두 구간에는 인스턴싱한 3D 코너 표식과 접근선을 추가했습니다. 기본 경로는 민트색, 검사된 정밀 경로는 금색으로 구별합니다.

## 충돌과 모바일 조작 수정

실제 시뮬레이션에서 세 결함을 재현하고 수정했습니다.

- 치명적인 소형 충돌 이후 같은 프레임의 수리·코인·링 수집이 계속되던 문제: 종료 즉시 나머지 수집·점수 처리를 중단합니다.
- 피해 재적용 대기 중의 실제 접촉이 근접 회피 보상으로 처리되던 문제: 실제 접촉과 근접 통과를 구분합니다.
- 장애물 배열 순서 때문에 더 뒤쪽 충격이 먼저 적용되던 문제: 이동 구간의 실제 접촉 시간순으로 처리합니다. 같은 시각의 대형 충돌은 소형 충돌보다 먼저 처리합니다.

움직이는 장애물의 이전·현재 위치를 충돌 범위에 반영하고, 근접 통과도 상대 이동으로 검사합니다. 대형 구조물의 즉사 규칙과 소형 충돌 보호막 규칙은 유지합니다. 회전하는 모든 삼각형에 대한 완전한 연속 충돌 해결을 새로 구현했다고 주장하지 않습니다.

좁은 세로 뷰포트에서 숨겨지던 F 확정 버튼을 다시 노출했습니다. 실제 터치 기기의 비행은 기존대로 가로 화면을 사용하며, 세로로 돌리면 일시정지와 회전 안내를 표시합니다. 출격 단계와 남은 시간, 완주/미완주 결과, 고정 재도전 버튼을 연결했습니다. 경로 선택과 출격 완료에는 별도 소리, 정밀 경로 통과에는 성공 효과를 연결하며 감소 모션 설정을 따릅니다.

실제 화면에서 성공 효과의 파편이 카메라 가까이 지나며 거대한 불투명 큐브처럼 보이는 문제를 확인했습니다. 카메라 근처 파편을 제거하고 접근 시 보이는 크기를 제한해 비행 경로를 가리지 않게 했습니다.

가까운 뒤쪽 고스트가 추적 카메라를 감싸며 크게 보이던 문제도 수정했습니다. 3D 고스트는 전방에서 거리에 따라 서서히 나타나고, 근접하거나 뒤처진 기록과의 차이는 HUD로 계속 확인합니다.

## 검증과 실행

검증 결과는 [VALIDATION-8.0.json](VALIDATION-8.0.json)에 기록합니다. 기존 45개 회귀 묶음에 출격 시계·저장, 출격 UI, 3분 실제 시뮬레이션, 경로 선택 형상, 충돌 무결성, 동일 항로·고스트·목표 묶음을 추가했습니다. 새 검사는 다음을 포함합니다.

- 30/60/144Hz 출격 시계, E 시간 제외, 단 한 번의 완료, 잘못된 시간·저장 값 거부.
- 세 난이도 × 네 기체, 총 12회의 원본 충돌 형상 기반 180초 자동 조종 완주.
- 원본 테마 13종의 경로 검사, 조건부 선택지 생성과 안전 검사 실패 시 비표시.
- 종료 후 수집 금지, 접촉과 근접 구별, 충돌 배열 순서 불변성, 저장·보상 중복 방지.
- 입력 속도와 시간을 달리한 동일 항로의 구조물 일치, 강화 후 재도전 조건 고정, 고스트 표본 제한·보간·호환 조건, 목표 달성 보상과 기록 보존.

자동 조종과 소프트웨어 GPU 브라우저 검사는 사람의 재미 평가나 실기기 FPS·발열 측정이 아닙니다. 22기체·13테마·원본 403모델과 공개 자산 파일을 보존합니다. 기존 7.0 검증은 [RELEASE-7.0.md](RELEASE-7.0.md)에 남겨 둡니다.

Node.js 22.13 이상에서 실행합니다.

```sh
npx --yes pnpm@11.25.0 install --frozen-lockfile
npm run dev
```

검사: `npm run typecheck`, `npm run lint:game`, `npm run test:game`, `npm run build`.
