# VOXEL AIRRUN 5.0.1 · Edition12

배포용 catalog에서 LOD0과 LOD1이 같은 파일을 가리키는 환경 모델은 두 번 다운로드·해독되고, 가까워질 때 같은 형상으로 다시 교체될 수 있었습니다. 실제 파일을 기준으로 로딩 대기열, 해독 결과, 애니메이션 준비, 재시도 지연과 사용 중인 자료의 보존을 공유하도록 수정했습니다. 서로 다른 네이티브 상세 파일은 각각 유지합니다.

현재 비·야간 상태를 적용한 후에 새로 도착하는 모델에도 같은 재질 상태를 즉시 적용합니다. 여러 메시가 같은 재질을 쓰는 경우 원래 거칠기·발광 값을 한 번만 기록해, 효과가 중복 누적되지 않도록 합니다. 기체 도색용 복제 재질도 같은 상태를 적용받습니다.

모델 파일·색상·텍스처·동작·충돌 자료와 배포 상세 단계 선택은 이번 수정에서 변경하지 않았습니다. 403종과 최고 근거리 단계의 891개 동작을 제공하며, 기체 22종과 환경 43종은 네이티브 LOD0, 환경 338종은 제공 팩의 LOD1을 사용합니다.

## 확인

- 수정 전 회귀 검사 6개 상황 중 5개가 실패했습니다. 같은 파일의 동시 LOD 요청에서 다운로드 2회가 관찰됐으며, 수정 후 다운로드·해독은 각각 1회입니다.
- 활성 객체 2개가 같은 자료를 공유할 때 한 객체를 중복 해제해도 다른 객체의 자료를 보존합니다. 마지막 사용이 끝나면 지오메트리를 한 번씩 해제합니다. 애니메이션 준비와 실패 후 재시도도 공유합니다.
- 전체 소스 자동 검사 29세트가 통과했습니다. 실제 배포용 catalog에서는 LOD 공유 모델 338종을 포함한 자료 보존 검사 696개가 통과했습니다.
- 실제 배포 구성으로 192초 연속 비행 검사와 30분 분량의 월드 자료 생성·해제 검사를 통과했습니다. 타입 검사와 배포 빌드도 통과했습니다.

실제 미리보기 브라우저는 `ERR_CONNECTION_REFUSED`로 연결되지 않았습니다. WebGL 화면, 실기기 FPS와 체감 성능은 직접 검증하지 못했습니다. 위 검사는 CPU·자료·수명 검사이며 GPU 성능 보장이 아닙니다. 기계 판독 결과는 `verification-5.0.1.json`에 기록합니다.
