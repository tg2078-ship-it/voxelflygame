# VOXEL AIRRUN 8.0.1 — 마지막 UI 마감

8.0의 선택 목표를 더 읽기 쉽고 반응이 분명하게 다듬었습니다.

- **단계별 보상 게이지:** 각 칸이 해당 단계에서 쌓은 진행량을 표시합니다. 목표가 3·6·9회일 때 4회 통과하면 첫 칸 완료, 둘째 칸 1/3, 셋째 칸 0으로 보입니다. 다음 보상까지 남은 횟수·거리를 바로 표시합니다.
- **달성 피드백:** 단계 달성 순간 게이지에 짧은 빛이 지나가고, 완료 단계 숫자가 반응합니다. 모두 달성하면 확보한 총 보상을 표시합니다. 반복 재생하는 효과는 넣지 않았습니다.
- **선택과 결과 카드:** 선택 버튼의 눌림·호버·키보드 포커스를 다듬고, 완수 카드에 단계 인장과 완료 배지를 추가했습니다.
- **접근성:** 진행 막대에 현재 값과 목표를 제공하고, 단계 달성만 상태 알림으로 전달합니다. 게임 설정과 운영체제의 감소 모션 설정을 모두 반영합니다.

검증 근거는 [VALIDATION-8.0.1.json](VALIDATION-8.0.1.json)과 `docs/validation/v801/`에 있습니다. 타입 검사·게임 린트·관련 기존 검사 3묶음·배포 빌드, 실제 브라우저의 키보드 선택과 UI 상태·세 가지 뷰포트·감소 모션을 확인합니다. HUD와 완수 카드의 브라우저 검사는 명시적인 상태 fixture를 사용하며 실제 비행을 완주한 검사로 계산하지 않습니다. 8.0의 전체 51묶음 회귀 결과는 [이전 검증 기록](VALIDATION-8.0.json)에 보존했습니다.

전체 ZIP은 새로 실행할 때 사용합니다. **8.0.1-update.zip은 8.0 전체 프로젝트에 덮어쓰는 소형 패치입니다.** 다른 버전에서 시작한다면 전체 ZIP을 사용하세요. 실행은 `START-HERE-KO.md`를 참고하세요. 외부 사이트는 게시하지 않았습니다.
