# 모델 로딩·동작 안정성 개선 검증

403종의 제공 모델을 검사했으며 카탈로그에 선언된 모든 시각 LOD 및 충돌 파일이 원본 프로젝트에 존재한다. 파일 누락을 기존 배포 사이트의 오류 원인으로 단정하지 않는다.

수정 내용:

- 일시적인 네트워크/서버 오류는 지연 후 최대 3회 시도한다. 403/404 또는 모델 대신 도착한 HTML 로그인/오류 페이지는 자동 반복 요청을 중지하고 실제 응답 종류를 설명한다. 명시적인 다시 시도로 파일 복구를 재검사할 수 있다.
- 충돌 파일에도 같은 유한 재시도 원칙을 적용한다. 비행 스트리머는 충돌 다운로드의 대기 상태를 존중해 매초 같은 실패를 다시 요청하지 않는다.
- 움직이는 모델의 드로콜을 줄이는 인스턴싱이 숨겨진 상위 노드·미리보기 받침대를 다시 노출할 수 있던 문제를 수정했다. 상위 노드를 숨기거나 복구할 때 인스턴스도 같은 상태를 따른다. 실제 사용자가 지적한 이미지의 바닥 문양과 동일한 원인이었는지는 별도 화면 대조가 필요하다.
- 동일 재질이 여러 비연속 그룹에 사용될 때 첫 그룹 이후의 삼각형이 누락되던 컴파일 문제를 수정했다. Worker와 CPU 대체 경로가 모두 원본 drawRange와 인덱스/비인덱스 형상을 보존한다.

실행한 검사:

- `node --import tsx tests/v2/asset-reliability.ts`: 39개 검사 통과. 오류 응답 분류, LOD 별칭의 공통 재시도, 수동 복구, 숨긴 상위 노드, 반복 재질 그룹과 drawRange의 Worker/CPU 일치를 확인했다.
- `node --import tsx tests/v2/model-residency.ts`: 6개 사례, 20개 검사 통과. 별칭 캐시, 참조 수명, 재시도 복구와 날씨 재질을 검사했다.
- `node --import tsx tests/v2/model-worker.ts`: 385종 환경 모델 컴파일, 40,268,016개 속성값 비교 오차 0, 4,750,098개 검사 통과. 실제 Worker 어댑터와 CPU 결과를 비교했다.
- `npx tsc --noEmit --incremental false`: 통과.

위 숫자는 CPU/기능 검증 결과다. 실제 브라우저의 영상·GPU 프레임 시간·장기 모바일 성능을 대신하지 않는다. 기체·모델 자산을 삭제하거나 낮은 디테일로 일괄 치환하지 않았다.

## 6.0 항로 구성과 초기 다운로드

해안은 작업 항만·어시장·교량 하구·등대 곶으로, 마을은 시장·방앗간·예배당 언덕·과수원으로, 도시는 유리 도심·철도역·건설 부두·시민 광장으로 나누어 같은 구간이 일관된 건물과 작업 설비를 사용한다. 해안 건물은 오른쪽 부두에 모이고, 실제 수면 높이에 배치한 배는 왼쪽 항로에서 이동한다. 등대를 슬라럼의 모든 기둥으로 복제하던 배치를 없애고 구간당 하나의 등대만 허용한다. 서울·부산 변형에는 강변 아파트·서울 타워·광안대교의 정체성을 유지한다.

구간의 보조 발견 모델은 최대 2개이며 해당 장소에 맞는 모델 중 시드에 따라 선택한다. 403종 원본과 381종 환경 모델의 테마 소속·모델 도감은 유지하지만, 첫 3분 동안 전체 도감을 강제로 전시하지 않는다. 원본 충돌 형상과 통과 경로, 건물의 물리적 바닥·부두 접지는 그대로 검증한다.

해안의 `high` 품질 초기 상주 목록은 모델 77개/충돌 파일 77개에서 각각 21개로 줄었다. 압축된 원본 모델·충돌 파일 크기의 합은 17,129,340바이트에서 8,915,390바이트로 48% 줄었다. 절차 생성 도입 전 대표 첫 구간의 추가 모델까지 포함한 측정은 24개, 9,410,702바이트였다. 현재 절차 항로의 실제 시작 전송량은 시드·기체·품질에 따라 달라진다. 이는 로컬 파일 크기 합계이며 HTTP 헤더·캐시·GPU 업로드 시간은 포함하지 않는다. 실제로 생성된 첫 구간의 모든 모델을 준비하고 다음 테마의 45초 전 다운로드는 유지한다.

추가 검사:

- `theme-coverage`: 44개 테마/변형/시드/기체 사례, 48,238개 검사 통과. 3분마다 서로 다른 19~34종의 모델이 추적 카메라 절두체에 진입한다. 단일 등대·부두와 배의 분리·발견 모델 상한·초기 모델 보존·다음 테마 준비·참조 해제를 검사한다.
- `world-revision`: 33,919개 물리·배치 검사 통과. 168개 패턴, 3개 시드의 원본 비례·바닥·실제 부두 표면·고속 항로를 검사한다.
- `audit-route`: 모든 패턴의 기준 항로와 원본 충돌 형상 간 충돌 0건.
- `audit-course`: 168개 기준 패턴의 통과 중심을 검사하고, 100개 절차 생성 시드의 무조작 생존을 별도로 검사한다. 첫 치명 구조물 이전에는 시드로 배치한 선택형 코인·링과 안내 경로로 조종을 익힌다.
- `audit-autopilot`: 22종 기체 × 3개 업그레이드 단계의 66개 제어 비행이 모두 240초를 통과한다. 이것은 제어 가능성 검사이며 재미에 대한 사람의 평가가 아니다.
