# VOXEL AIRRUN 9.0.0

3분 출격과 테마 전환 간격이 모두 180초여서 출격 내내 해안만 반복되던 문제를 해결하고, 정밀 비행을 적극적인 능력 사용으로 연결했습니다.

## 플레이

- **네 지역의 여정:** 해안 → 마을 → 도시 → 시드로 선택한 숲·빙하·사막·강·폭포 지역. 지리적 전환은 재현 가능한 순항 거리 기준이며 실제 속도와 조작에 따라 도달 지역이 달라집니다. 완주 조건은 기존처럼 수동 비행 180초입니다. 기본 출격 모드를 3분 출격으로 바꿨으며 무한 비행과 오늘의 항로도 선택할 수 있습니다.
- **러시 / Q:** 초기 충전 25%에서 링 수집·정밀 통과로 충전합니다. 100%에서 Q 또는 화면 버튼으로 5초 가속과 코인 자석을 발동합니다. 감속이 우선하며 충돌 면역은 주지 않습니다. 기존 터보와 속도 배율을 중첩하지 않습니다. 피격은 러시를 중단하고 충전을 30% 낮춥니다. E 연출·일시정지·포커스 이탈로 충전이나 시간이 부당하게 늘어나지 않도록 처리했습니다.
- **항로·지형 일치:** 출격의 테마, 미리 불러올 자산, 실제 생성된 구간을 같은 거리 기반 일정에 맞췄습니다. 구간 경계를 지형 청크와 맞춰 다른 테마의 바닥이 섞이는 문제를 줄였습니다. 기존 코인·기체·기록은 보존하고 이전 코스의 잔상을 새 코스에 표시하지 않습니다.

## 화면과 반응

- 격납고의 새 여정 안내, 출격 카드·기체 선택·작업실·메뉴의 일관된 색상과 배치.
- 비행 화면의 지역 진행 표시·지역 진입 연출·러시 충전 및 발동 버튼·계기판 정리. 모바일에서 경로 안내와 속도계의 겹침을 해소하고 기체 중앙 시야를 확보했습니다.
- 결과 화면의 실제 도달 지역, 지역별 비행 시간, 러시 사용 횟수와 비행 거리.
- 러시 준비·발동 효과음과 러시 중 음악 강도 변화. 모션 감소와 음량 설정 적용.
- 로딩 안내를 플레이어가 이해할 수 있는 출격 단계로 정리. 다음 지역은 이륙 후 미리 준비해 첫 출격이 불필요한 다운로드를 기다리지 않게 했습니다.
- 격납고에서 기체·카메라·화면 크기가 그대로일 때 수천 개 표본의 카메라 맞춤 계산을 재사용합니다.

## 검증 범위

`tests/v2/ace.ts`는 러시의 충전·중복 방지·실제 가속·감속 우선·시간 제한·기록 검증과 거리 기반 지역 생성을 확인합니다. 추가로 숲·빙하·사막·강·폭포의 다섯 마지막 지역에 대해 실제 항로를 따라 러시를 충전·발동하며 네 지역을 완주하는 자동 조종 검사를 수행합니다. `tests/v2/sortie-flight.ts`는 원본 충돌 모델을 사용하는 자동 조종으로 난이도 3종 × 기체 4종의 180초 완주를 검사합니다. 기존 전체 회귀 검사, 타입·린트·정적 빌드와 Chromium UI 검증도 수행합니다.

브라우저 검증은 소프트웨어 GPU 환경입니다. 실제 사용자 하드웨어의 FPS, 인간 플레이테스트의 재미 또는 AAA 상용 수준을 보증하는 자료는 아닙니다. 기존 기체 22종·모델 403개·애니메이션 클립 891개를 유지합니다.

검사 결과: 전체 53개 검사 묶음을 실패 항목 수정 후 이어서 실행해 모두 통과했습니다. 무한 비행 66회·3분 출격 12회·러시 여정 5회의 자동 조종 검사, 타입·린트·배포 빌드, Chromium 출격·일시정지·결과 저장 검증을 완료했습니다. 844×390과 736×320 터치 배치에서 계기판 겹침과 기체 중앙 시야를 확인했습니다. 마지막 브라우저 검사에서 JavaScript 오류와 HTTP 실패는 0건이었습니다. [기계 판독 검증 기록](validation/release-9.0.0.json)
