# VOXEL AIRRUN 4.3 — 화면 선명도와 장면 일관성

## 구현한 변경

- 기본값은 HIGH·125%·자동 해상도 꺼짐입니다. 기존 v3 저장에 새 선명도 필드가 없을 때 한 번만 같은 설정을 적용합니다. 기존 BALANCED 자동 선택은 HIGH로 이전하며, 이후 사용자가 선택한 BALANCED와 해상도는 그대로 저장합니다. 화폐·기체·강화·기록은 변경하지 않습니다.
- 격납고 설정과 비행 중 일시정지 설정에 100·125·150% 및 ULTRA·125% 화질 우선 버튼을 연결했습니다. 해상도 선택은 자동 해상도를 끕니다. 높은 설정은 그래픽 부하를 증가시킵니다.
- 프로필의 기본 DPR 상한은 BALANCED 1.5, HIGH 2, ULTRA 2.5입니다. 선택 배율을 이 기본 해상도에 곱합니다. 자동 해상도를 다시 켜도 기본 DPR 아래로 내리지 않습니다. 이전 코드는 0.8 DPR까지 내려갈 수 있었습니다. 기기의 전체 물리 해상도를 무조건 보장한다는 의미는 아닙니다.
- EffectComposer의 실제 반정밀도 렌더 타깃에 HIGH 최대 2, ULTRA 최대 4 MSAA를 적용합니다. 현재 GPU가 RGBA16F 형식에 보고한 표본 수만 사용하며 지원하지 않으면 SMAA를 사용합니다. SMAA는 설치된 Three r186의 요구대로 OutputPass 앞에서 실행합니다. 기존 FXAA는 제거했습니다. 실제 지원 여부와 GPU 출력은 이번 환경에서 측정하지 못했습니다.
- 텍스처 이방성 필터를 프로필별 최대 4·8·16, 기기 지원 범위 내에서 적용합니다. 현재 로드된 지도와 이후 도착하는 지도 모두 갱신하며 원본 UV와 색상·필터 모드는 보존합니다. 접촉 음영의 해상도도 실제 출력 DPR에 연결했습니다.
- 중간 세부 모델의 유지·선택 거리를 늘렸습니다. HIGH·ULTRA는 충돌 경계가 호환되는 LOD1을 테마 기본 모델로 유지합니다. LOD1 경계가 잘못된 원본은 호환되는 LOD2로 대체해 기본 모델 전체를 불필요하게 LOD0로 강제하지 않습니다. 화면에서 크게 보이는 근거리 풍경도 충돌 플래그 없이 LOD0를 사용합니다. 4초 앞의 해당 상세 모델을 미리 요청합니다.
- 고화질 모델 준비 중 기존 장면을 유지하는 4.2 흐름을 보존합니다. 테마 전환 45초 전 준비, 필수 기본 모델 우선순위, 보이지 않는 충돌 방지도 유지합니다. 원본 메시·애니메이션·테마 모델을 새 에셋으로 교체한 업데이트는 아닙니다.
- 일반 비행에 항상 걸리던 색수차와 인공 그레인을 제거하고 가장자리 암부·블룸·HTML 그라데이션을 줄였습니다. E·부스트 효과는 유지합니다.
- 하늘 지평선과 동일한 선형 색 계산을 거리 안개와 수면에 적용합니다. 노을·일출·구름·밤의 변화를 공유하며 수면 반사광은 실제 태양 방향을 사용합니다. 태양광·환경광의 색 전환은 연속 보간하며 야간 실내 환경 반사의 세기도 낮춥니다.

## 검증 범위

`visual-quality`는 저장 이전·손상 입력 거절·실제 설정 메서드·UI 이벤트·SSR 접근성·원본 카탈로그의 호환 LOD·테마 캐시 보존과 해제·텍스처 필터·실제 환경 갱신 메서드를 검사합니다. 렌더러 경계는 대체 객체로 검사하며 실제 WebGL을 실행하지 않습니다. 전체 25개 게임 회귀 검사(367초), 타입 검사, 배포용 빌드가 통과했습니다. 새 화질 검사는 2,515개 조건을 검사했습니다. 결과는 `verification-4.3.json`과 `verification-4.3.txt`에 기록합니다.

추가 CPU 장면 점검은 HIGH, 시드 44171, 해안·도시·숲, 각 6초 사례입니다. 새로운 장면의 잠재 메인 패스 draw는 609·549·382, 삼각형은 약 199만·216만·246만, 장면 형상 메모리는 47.16·50.79·95.09 MiB였습니다. 이는 프러스텀·그림자·후처리를 포함한 실제 GPU draw나 FPS가 아닙니다. 상세 모델을 늘렸으므로 이전보다 메모리·형상 비용이 증가합니다. 실제 기기 성능 개선으로 표현하지 않습니다.

이 작업 환경에는 지원되는 브라우저 제어 도구가 없어 실제 GPU 화면, 안티앨리어싱 결과, 모바일 레이아웃과 기기 FPS를 확인하지 못했습니다. 코드·CPU·SSR 검증의 통과가 사용자가 체감하는 화질과 재미를 보증하지 않습니다.
