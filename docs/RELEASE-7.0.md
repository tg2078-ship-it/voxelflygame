# VOXEL AIRRUN 7.0 — 플레이 경험 리빌드

첨부된 상용 게임 리빌드 요청을 기준으로 6.0의 실제 코드·실행 화면·점수 판정·로딩·입력·보상 설명을 다시 검토했습니다. 이번 결과는 실행 가능한 프로젝트와 원본 자산입니다. 유료 출시 품질이라는 목표와, 자동 검사·소프트웨어 GPU에서 확인한 범위를 구분합니다. 외부 사이트에는 게시하지 않았습니다.

## 재평가와 선택

| 분류 | 대상과 근거 | 적용 |
|---|---|---|
| 유지 | 22기체·13테마·403원본, 실제 모델 동작/삼각형 충돌, 워커와 저장 구조, 절차 항로·데일리 | 기존 콘텐츠와 기록을 축소하지 않고 유지 |
| 대폭 개선 | 직진 가속이 작전으로 인정되지 않음, 빈 안내 구간의 협문 보상, 한 행동의 중복 정밀 판정 | 실제 수동 가속 거리 인정, 장애물 없는 안내의 위험 보상 제외, 겹친 안내 링/표식은 한 번의 정밀·플로우 행동으로 인정 |
| 재설계 | 연속 보너스가 즉시 확정돼 플레이어의 판단 여지가 적음 | 미정산 플로우를 계속 키울지 확정할지 선택하는 원장·입력·HUD·정산·저장 연결 |
| 추가·보완 | 평가점수만으로 훈장 이유를 알기 어려움, 잠긴 기체의 구매 동선, 작은 조작 표적 | 공유 훈장 조건, 실제 보너스 내역과 다음 목표, 잠긴 기체 선택 시 구매 콘솔, 잔액·변화량 설명, 선택형 비행 안내 |
| 최적화 | 조작 중 동기 GPU 캡처, 화면 밖 테마 일괄 촬영, 폐기한 스트림의 뒤늦은 후속 작업 | 입력·가시성·프레임 시간에 따라 미리보기 준비/캡처 제어, 폐기 후 요청·상태 변경 차단 |

전체 엔진 교체는 선택하지 않았습니다. 원본 형상·동작·충돌과 기존 기능을 검증한 렌더링/워커 구조는 유지하고, 실제 플레이의 판단·보상·응답성을 떨어뜨리던 부분을 재설계했습니다. 403종을 모두 새로 모델링했다고 주장하지 않습니다.

## 계속 밀어붙일지, 확정할지

링·정밀 통과·근접·협문 같은 수동 비행 행동으로 플로우 배율을 쌓습니다. 배율로 생기는 **추가 보너스**는 바로 총점에 더하지 않고 미정산으로 표시합니다.

- **F 또는 확정 버튼:** 표시된 미정산 점수를 확보하고 현재 체인·배율을 다시 시작합니다.
- **계속 연결:** 높은 배율을 유지하지만 피격·추락·마지막 유효 행동 뒤 8초 단절 때 미정산분을 잃습니다.
- **기본 점수·정밀·작전 보상:** 위 위험에 묶이지 않고 기존처럼 지급됩니다.
- **E:** 사용 직전에 미정산분을 자동 확보합니다. 연출 중 수동 비행 보너스를 만들지 않습니다.
- **직접 비행 종료:** 미정산분을 반영한 순수한 결과 미리보기로 안전하게 정산합니다. 결과를 여러 번 읽거나 체크포인트를 작성해도 비행 중 점수가 바뀌지 않습니다.
- **갑작스러운 중단 복구:** 체크포인트에 확정된 점수만 정산하고 미정산분은 소실로 기록합니다.

점수 ×2 효과는 행동이 발생했을 때 추가 보너스에 반영합니다. 뒤늦게 효과를 얻거나 효과가 끝나도 확정 버튼에 표시한 금액이 다시 배가되거나 달라지지 않습니다. 미정산·확정·소실 합계는 정수로 보존하며 같은 지급을 반복할 수 없습니다. 과금·재료 수집·대기 시간을 추가하지 않았습니다.

## 정확한 규칙과 알아보기 쉬운 결과

직진 가속도 수동 비행입니다. 불필요한 흔들기를 요구하던 작전 진행 조건을 수정했습니다. 첫 안내 구간의 링과 같은 위치의 방향 표식은 목표 두 종류에 관찰될 수 있으나, 한 번의 물리적 통과로 정밀·플로우 보상을 두 번 만들지 않습니다. 실제 교량의 위험 경로와 근접 보상, 중복 지급 방어는 유지했습니다.

결과 화면에는 작전·정밀·확정 플로우·기타 보너스와 미정산 소실을 분리해 실제 총점에 맞춰 보여줍니다. 다음 훈장의 평가점수·수동 비행 시간·작전 수를 설명하고 부족한 조건을 표시합니다. E 시간을 제외한 수동 시간을 새 기록에 보관합니다. 이전 E 기록에서 복원할 수 없는 수동 시간을 만들어내지 않습니다.

대형 구조물 충돌은 내구도·보호막과 무관하게 종료되는 기존 규칙을 유지했습니다. 보호막은 소형 충격을 막습니다. 비행 안내와 실패 조언에서 이 차이와 감속·경로 선택을 설명합니다. 이전 저장 스키마를 버리거나 기록을 초기화하지 않습니다.

## 입력·화면·보상

격납고에 첫 목표와 선택형 비행 안내를 넣고 WASD/방향키·가감속·기어·F의 실제 동작을 설명합니다. 안내는 강제 관문이 아니며 Escape·키보드 포커스 복귀를 지원합니다. 화면 내 확정 버튼은 미정산 금액과 남은 연결 시간을 보여줍니다.

잠긴 기체를 고르면 구매 콘솔로 연결하고 필요한 코인·부족액·구매 후 잔액을 표시합니다. 강화 전후의 실제 성능과 지급 결과를 설명합니다. 기어 설정에 맞춰 Shift/Space 설명을 바꾸고, 주요 터치 표적과 짧은 가로 화면의 글자·스크롤 여유를 보완했습니다. 긴 결과 화면에서도 재도전·복귀 버튼을 고정하고, 모바일 세로 결과는 한 열로 읽히도록 했습니다.

## 불필요한 준비 작업 줄이기

미리보기는 선택한 테마와 실제 보이는 카드부터 준비합니다. 화면 밖 대기/진행 작업을 취소하고, 드래그·입력 대기·최근 조작 중에는 무거운 촬영을 연기합니다. 프레임이 느릴 때 캡처 간격을 늘리고 한 번에 하나만 처리합니다. 미리보기의 원본 상세도를 낮추지 않았습니다.

초기 모델 라이브러리의 기체·기초 공항 자산 구간은 3,505,563바이트에서 1,958,551바이트로 약 44% 줄었습니다. **전체 앱 다운로드나 로딩 시간·FPS의 감소율이 아닙니다.** 공항의 나머지 실제 자산과 비행 시작에 필요한 모델·충돌 자료는 해당 단계에서 준비하며 전체 카탈로그는 유지합니다.

숨겨진 탭에서는 렌더·물리 누적을 멈추고 복귀 시 시계를 재설정합니다. 프레임 처리가 중단되기 전에 오디오에도 일시정지 상태를 즉시 적용합니다. 폐기된 스트림이 뒤늦게 충돌 파일을 요청하거나 실패 상태를 되살리는 경우도 차단했습니다.

## 시각·소리·움직임

낮은 품질에서도 덜 완성된 거대한 구름판 대신 완전한 구름 형태를 유지하도록 밀도·높이·폭을 조정했습니다. 수면과 장면의 안개 계산을 맞추고 밤의 물·구름·수평선 구분을 다듬었습니다. 낮·노을·폭풍·밤을 같은 최종 색 변환 경로로 비교했습니다.

작전·정밀 통과·플로우 확정에 실제 월드 효과를 연결했습니다. 성공 파동이 비행기를 따라붙던 위치 문제, 프레임률에 따라 달라지던 잔해 운동, 비어 있는 효과 렌더 제출을 수정했습니다. 감소 모션 설정은 폭발·파동·플래시에 실제로 반영됩니다. F 확정에는 별도 음형을 연결했습니다.

## 실행과 검사

Node.js 22.13 이상, pnpm 11.25.0을 사용합니다.

```sh
npx --yes pnpm@11.25.0 install --frozen-lockfile
npm run dev
```

터미널의 로컬 주소(기본 `http://localhost:5173`)를 엽니다.

```sh
npm run typecheck
npm run lint:game
npm run test:game
npm run build
```

자동 회귀 45개 묶음이 전체 실행에서 통과했습니다. 이후 실제 플레이에서 발견한 프레임 사이 중복 판정을 수정하고, 점수 무결성 141개와 핵심·작전·정산·데일리·성장 관련 묶음을 다시 실행해 통과했습니다. TypeScript·게임 ESLint·배포용 빌드도 통과했습니다. 주요 근거는 다음과 같습니다.

- 미정산 원장: 64개 시드·38,400개 사건의 지급/소실/보존, 잘못된 입력·중복 지급·순수한 종료 투영 검사.
- 실제 점수 연결: 체크포인트가 점수를 지급하지 않음, F 지급 1회, 피격/시간 만료/추락, 행동 당시 ×2, E 정산, 중단 복구와 이전 저장 검사.
- 실제 절차 안내 3시드·교량 위험 경로·직진 가속·E 제외를 원본 충돌과 실제 시뮬레이션으로 검사.
- 보이는 테마 우선·입력 중 촬영 연기·화면 밖 취소·폐기 후 상태·브라우저 단축키 충돌 검사.
- 원본 403종, 기존 저장·성장·보상, 66개 4분 제어 비행, 속도별 CPU 스트리밍·E 경로·모델 워커 회귀 포함.
- 30/60/144Hz 잔해 운동과 감소 모션, 낮·노을·폭풍·밤의 이전/신규 WebGL 장면 8개에서 오류 0건. 이 장면 검사는 전체 게임의 기기별 FPS 측정이 아닙니다.

## 실제 브라우저 확인

확정된 소스를 새 Chromium에서 실제 키보드로 조종했습니다. 첫 작전 완료, 미정산 **22점 → F 1회 → 확정 22점·체인/배율 초기화**, 부스트, 일시정지 시간 동결, 결과·데일리 기록 저장을 확인했습니다. 두 안내 통과는 정밀·플로우 행동도 각각 두 번만 집계됐습니다. 해당 실행의 JavaScript·WebGL·HTTP 오류는 0건이었습니다.

별도 실제 클릭/키보드 검사에서 비행 안내의 Escape·포커스 복귀, 잠긴 기체 구매 600코인, 강화 45코인과 실제 성능 변화, 1280×800·390×844·844×390의 버튼 도달·넘침을 확인했습니다. 긴 결과의 버튼 검사는 실제 비행의 점수/평가를 사용한 화면 배치용 fixture이며 추가 비행 점수 검증으로 세지 않습니다. 브라우저는 SwiftShader 소프트웨어 GPU입니다.

구조화된 결과와 최종 소스 해시는 [VALIDATION-7.0.json](VALIDATION-7.0.json)에 있습니다.

## 목표 품질과 확인한 범위

| 평가 | 근거와 남은 범위 |
|---|---|
| 첫인상·UI | 실제 모델과 안내·상태·오류·결과 설명을 구현. 가독성의 주관적 평가는 사용자 플레이에서 확인 필요 |
| 게임성 | 보너스 보존과 배율 유지의 실제 선택, 잘못된 보상·가속 조건 수정. 사람 대상 재미·장기 재도전 평가는 미실시 |
| 시스템 | 점수 원장·파워업·E·저장·정산이 연결되며 중복 지급/불일치 검사 통과 |
| 콘텐츠 | 22기체·13테마·403원본과 절차 항로·난이도·성장 유지 |
| 안정성 | 45개 회귀 묶음·빌드 통과. 실제 장시간 GPU 플레이와 모든 기기 보장은 아님 |
| 성능 | 준비 바이트·불필요한 작업 감소를 확인. 목표 PC/모바일의 FPS·발열·메모리 상한은 미측정 |
| 상품성 | 유료 출시 합격 판정을 하지 않음. 실기기 성능·접근성·장시간 플레이와 외부 사용자 평가가 남아 있음 |

자동 검사와 소프트웨어 GPU 화면을 판매 가능한 완성도의 증명으로 확대하지 않습니다. 실제로 실행해 판단할 수 있도록 전체 소스·자산·실행/빌드 방법과 변경 근거를 제공합니다. 6.0의 이전 검증은 [RELEASE-6.0.md](RELEASE-6.0.md)에 별도로 보존합니다.
