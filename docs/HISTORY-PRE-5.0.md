# VOXEL AIRRUN 4.1

사용자가 제공한 Edition 9 GLB 팩과 `docs/voxel_flight_plan_v2.0.md`를 바탕으로 만든 PC·모바일 가로 화면용 무한 비행 게임입니다. ZIP 이름은 `400`이지만 실제 팩은 **403종: 기체 22종, 환경 381종**입니다. 원본 기획서의 연습 모드와 넓은 비행 범위는 이후 사용자 요청에 따라 변경했습니다.

조종사 카드 발급·승인 → 공항 → 수직으로 열리는 격납고 → 기체 선택·강화 → 경로 준비 → 자동 이륙 → 무한 비행 → 결과 정산으로 이어집니다. 기체와 비행 경로의 충돌 모델이 준비되기 전에 비행 시계를 진행하지 않습니다.

## v4.1 업데이트

- 코스가 같은 아치로 되돌아가던 선택을 바꾸고, 테마 모델의 위치·크기·방향을 다양하게 배치했습니다.
- 호환되는 LOD 선택, 지형·모델 결합 작업 스레드, 원본 부품 인스턴싱과 캐시 수명 수정으로 렌더링과 로딩 비용을 줄였습니다.
- 큰 기체의 구간 연결 충돌, 여러 손가락 입력, E 버튼, 작은 가로 화면의 계기 배치를 개선했습니다.
- 22개 검사 세트, 작업 스레드의 원본 형상·UV·색 보존, 66회 조종 비행과 E 352+216개 사례를 검증했습니다. 실제 브라우저 화면과 기기 FPS는 미확인입니다.

상세 내용과 CPU 장면 수치: [4.1 변경 및 검증](docs/RELEASE-4.1.md).

## 이전 v3.0 업데이트

- 사용자 제공 400종의 Hero/Gameplay/Distance 1,200개 GLB, 원본 JPEG·UV·PBR·피벗·키프레임을 유지합니다. 움직이는 200종의 고유 클립은 771개입니다. 보조 교통 4종은 별도이며 모든 모델을 같은 테마에 배치하지 않습니다.
- 활주로 앞 접근등 받침을 제거했습니다. 바다를 덮던 거대한 회색 공항 면을 실내 바닥으로 축소하고, 유한한 녹지 곶과 흙 단면으로 활주로를 지지합니다.
- 원본 고체 542,153개와 BVH를 통합했습니다. 실제 회전 형상의 빈 모서리는 충돌하지 않으며, 관절 충돌은 렌더 원점과 독립적으로 같은 원본 애니메이션 시간에서 계산합니다.
- 가까운 충돌 모델은 Hero LOD0를 준비합니다. 시각 LOD가 생략한 지붕이나 장식의 보이지 않는 충돌을 방지하고, 가까운 움직이는 부품은 낮은 품질에서도 정지시키지 않습니다.
- 어촌·어시장·해안 저택, 마을 회랑·작업장·방앗간, 도시 도서관·역·트램·관절 버스와 테마별 새 건축을 추가했습니다. 접지·부두·수선을 유지하고 기존 경로를 보호합니다.
- 선택 기체 16종, 실제 모델 크기, 조종면 최대 편향과 착륙장치 수납을 반영했습니다. 기체 컬렉션은 가로 스크롤로 둘러봅니다.
- 더 작은 복셀 구름과 높이별 일출·노을 팔레트, 이동하는 태양을 사용합니다. 로비에서 비행으로 넘어갈 때 날씨/구름 갱신 시계가 멈추던 오류를 수정했습니다.
- E의 정밀 경로 검색을 별도 Web Worker로 옮겼습니다. 충전 표시 동안 물리 시계를 멈추고 경로와 모델이 준비된 뒤 15초를 시작합니다. 취소·일시정지·실패·오래된 응답은 횟수를 소모하지 않습니다.
- 필요한 구간의 압축 충돌 자료만 읽고, 원본 이미지 해시·LOD별 인덱스·샘플러·UV·색 공간으로 텍스처를 공유합니다. 마지막 참조가 끝나기 전에 GPU 자원이나 비트맵을 폐기하지 않습니다.

[모델 통합·복구·검증 기록](docs/validation/asset-400-integration.md)에 자산 대응과 재현 경로를 남겼습니다. 실제 GPU 화면과 PC/모바일 FPS는 별도 실기기 확인이 필요합니다.

## v2.2 인게임 변경

- 해안은 부두·창고·컨테이너·급유소·선박·크레인과 녹지 곶·해변·섬이 이어집니다. 마을과 도시도 실제 비율의 건물, 도로, 레일·차량을 사용합니다. 건물 구획은 통과 경로와 기존 구조물을 침범하면 배치하지 않습니다.
- 필수 아치·교량은 원본 비율을 유지하고 실제 지면·수면에 붙입니다. 통과 높이가 물리적으로 열린 공간 안에 오도록 경로를 조정합니다. 물 위 건물에는 해저까지 내려가는 부두를 제공하고, 배는 비행 고도가 아닌 수선에 놓습니다.
- 단조로운 거대 계단형 해안을 제거하고 지형·충돌의 높이 함수를 통일했습니다. 자연 모델은 해당 품질에서 렌더되는 실제 지형 삼각형과 발자국 높이를 기준으로 심습니다. 상세 영역 바깥에도 낮은 해상도의 능선이 이어집니다.
- 다음 모델을 준비하는 동안 현재 비행 장면·기체·카메라·시간을 유지합니다. 340m 출발 활주로는 시간 제한으로 지우지 않고, 실제 이동으로 뒤로 벗어납니다. 일시정지·결과·구간 준비가 공항을 다시 불러오지 않습니다.
- 4초 이륙은 선택 기체의 실제 출발 속도로 이어집니다. 고정 물리 계산 사이의 기체·월드 이동을 보간하고, 카메라 위치와 시선도 함께 감쇠합니다. 배기·보호막·날개 궤적은 보간된 기체 위치에 붙습니다.
- 고속 구간 조정은 필수 통로의 지지 구조를 조정합니다. 주변 건물·도로·레일과 배를 함께 옮기지 않습니다. 장애물 밀도가 진행 거리에 따라 계속 늘어나는 규칙은 없습니다.
- 하늘의 회색 덮임과 공기 중 흐림을 완화하고, 가까운 구름 덩어리와 수면의 월드 좌표 이동을 조정했습니다. 기존 낮밤·날씨·조명 설정을 유지합니다.

## v2.1 변경

- 바다를 격납고에서 분리하고, 고체 콘크리트 바닥·정비 플랫폼·벽·천장 트러스·작업대·설비·조명·접촉 그림자로 구성한 격납고를 사용합니다.
- 기체가 중심에 오도록 화면의 실제 빈 영역과 모델의 정점을 계산합니다. 드래그 회전, 휠·핀치 확대, 정면·측면·후면·윗면·초기화 버튼을 제공합니다. 카메라는 격납고 안에 머뭅니다.
- 로딩은 기체 설계도와 실제 준비 진행률을 사용합니다. 호출명 확인·카드 발급·승인 스탬프를 순서대로 연출하고, 설정에서 카드 재발급으로 다시 볼 수 있습니다. 게임 프로필은 해당 브라우저에 저장됩니다.
- 기체 선택 카드와 테마 사전은 같은 WebGL 렌더러로 촬영한 게임 모델 이미지를 사용합니다. 실제 비행에서 촬영한 발견 이미지가 우선하며, 비행 전 장면에는 `게임 렌더 미리보기`를 표시합니다. 생성 일러스트나 CPU 투영 그림을 실제 플레이 캡처로 표시하지 않습니다.
- 보상·기체 해금·강화에 배지, 광선, 코인 집계, 입자와 전용 소리를 연결했습니다. 표시 연출은 이미 처리된 거래를 보여 주며 보상을 다시 지급하지 않습니다.
- 공개 연습 비행과 강화 전후 연습 출격을 제거했습니다. 내부 환경 설정 타입은 장면 촬영·기존 저장 호환·자동 검사를 위해 유지합니다.
- 일반 비행 범위는 좌우 ±42m·최고 62m로 좁혔습니다. 테마에 맞는 구조물로 통로를 만들고, 도시·마을·전통 마을에는 연결된 실제 비율의 건물군을 배치합니다. 바깥 지형은 자연 풍경으로 구성합니다.
- 선박·차량·열차의 위치와 조작 가능한 관절 모델의 원본 애니메이션을 매 프레임 갱신합니다. 로딩을 기다리는 인스턴스 배치도 이동 좌표를 갱신합니다.
- 일출·낮·노을·밤 조명과 구름의 상단·중간·하단 색 변화, 비·눈·안개·바람·젖음·번개를 연결했습니다. 구름은 색 갱신 사이에도 계속 이동합니다.
- Shift는 무제한입니다. 파란 배기·날개 궤적·수증기, 시야각·색 보정과 아주 약한 화면 흔들림을 더했습니다. 열기 표시는 연출이며 가속을 차단하거나 피해를 주지 않습니다.
- 확인된 회색 암석 5종의 하단 색 대비를 완화했습니다. 상단 색, 식생, 기체 팔레트, 유리와 항법등, 기하·충돌 형상은 보존합니다.
- 실패한 모델 다운로드에는 제한된 재시도 간격과 시간 제한을 적용합니다. 선택한 기체의 LOD를 매 비행 단계에서 반복 교체하지 않습니다. 실패가 지속되면 출격·진행을 멈추고 명시적인 재시도를 제공합니다.

## 조작

| 입력 | 동작 |
|---|---|
| W / ↑ · S / ↓ | 상승 · 하강 |
| A / ← · D / → | 좌 · 우 |
| Shift | 누르는 동안 목표 속도 ×1.35, 사용 제한 없음 |
| Space | 누르는 동안 목표 속도 ×0.70 |
| E | 한 판 한 번, 15초 하이퍼 트릭·무적 |
| Esc | 일시정지 · 재개 |
| 모바일 가로 화면 | 가상 조이스틱·가속·감속, 멀티터치 |
| 모바일 E | 기체 엠블럼 0.8초 길게 누르기 |
| 격납고 | 드래그 회전, 휠 또는 두 손가락 확대 |

홀드 해제 시 현재 거리의 기본 속도로 부드럽게 복귀합니다. 선택형 기어는 0.70 / 0.85 / 1.00 / 1.15 / 1.35의 5단이며 기본은 3단입니다. 탭 숨김·포커스 상실·모바일 세로 회전 시 일시정지하고 3초 카운트다운으로 재개합니다. 준비 중에 포커스를 잃어도 바로 자동 비행하지 않습니다.

## 월드와 성장

해안 → 마을 → 도시가 각각 180초 진행되고, 9분 이후 13개 테마와 한국 4변형을 시드에 따라 이어갑니다. 168개 패턴은 서로 다른 좌우·상하 경로와 안전·위험 보상 경로를 갖습니다. 장애물 수를 거리에 따라 끝없이 늘리는 규칙은 없습니다. 기본 속도는 `40 + 12 ln(1 + d/600) + 0.0006d` m/s이며 d는 전진 거리 m입니다.

22종 기체, C/B/A/S 등급, Lv.1~20 전체 성능 강화, 도장, 64개 퀘스트·20개 진로 미션·40개 업적을 제공합니다. `미션 변경권`은 미완료 목표를 같은 계열·등급의 다른 목표로 바꾸고 진척을 초기화합니다. 한 판에서 500m 또는 30초를 비행하면 1장 획득하며 최대 3장까지 보관합니다.

보상은 `floor(거리/30) + floor(추가점/180) + 수집 코인`입니다. 보상 정산, 업적 수령과 중단 비행은 중복 지급하지 않습니다. 일반/E·전체/기체별 최고 기록과 최근 20판, 발견 이미지, 설정을 IndexedDB에 보관합니다. 기존 저장 이전과 JSON 백업 검증·복원을 지원합니다.

E는 상승·롤·반전·S자·하강·정렬과 실제 공간 이동·카메라·푸른 궤적·음향을 사용합니다. 15초와 복귀 후 3초의 경로를 검사합니다. 충돌 없는 경로를 만들지 못하면 횟수를 소비하지 않고 재시도를 안내합니다. 모든 시드에서 즉시 발동한다는 보장은 하지 않습니다.

## 설정과 개발

Balanced/High/Ultra는 실제 DPR·그림자 해상도·AO·bloom·구름 수·지형 간격·상세 모델 거리·애니메이션 예산·비 입자 수를 바꿉니다. 30/60FPS 목표, 자동 해상도, 언어, 홀드/기어, 조종 감도, 음량, 흔들림 감소, 이륙 스킵과 터치 좌우 교환을 설정합니다. 비행 중 일시정지 메뉴에서도 주요 설정을 바꿀 수 있습니다.

Node 22.13 이상과 pnpm 11, Vinext·React·Three.js·Zustand를 사용합니다. 현재 런타임은 `app/airrun/`이며 `app/game/`은 이전 저장과 검사 호환을 위해 남아 있습니다.

```sh
pnpm install
pnpm typecheck
pnpm lint:game
pnpm test:game
pnpm build
```

`test:game`은 19개 세트를 별도 Node 프로세스에서 실행합니다. Edition 9 데이터 검증은 `docs/validation/asset-edition9-*.json`, 게임 검사 결과와 한계는 [IMPLEMENTATION.md](docs/IMPLEMENTATION.md)에 있습니다.

자동 검사는 실제 GPU 화면, 실기기 FPS·발열·멀티터치와 사람의 재미 평가를 대신하지 않습니다. PC High 60FPS와 모바일 Balanced 30FPS는 측정된 결과가 아닌 목표입니다. 온라인 계정 동기화·전 세계 랭킹·실제 광고 제공자 연결은 포함하지 않습니다.
