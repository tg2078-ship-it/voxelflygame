# VOXEL AIRRUN 9.1.0

무한 비행을 기본 출격으로 되돌리고, 비행 화면의 정보량과 규칙적인 항로 배치를 줄였습니다.

## 메인 모드와 화면

- 새로 열면 무한 비행이 선택됩니다. 격납고의 첫 모드 버튼도 무한 비행이며, 3분 출격과 데일리는 ‘다른 비행 모드’에서 고릅니다.
- 기존 13개 테마와 무한 모드의 지역당 180초 순환을 그대로 유지합니다. 9.0의 네 지역 여정은 선택형 3분 출격에만 해당하며 테마를 삭제한 것이 아닙니다.
- 기본 HUD는 거리·점수·다음 통과점·짧은 작전 안내·기체 상태·속도·러시에 집중합니다. 중복 경로 카드, 긴 조작 안내, 비어 있는 연속 점수 패널을 숨겼습니다. ‘상세 계기판’으로 기존 정보를 다시 펼칠 수 있습니다.
- 모바일에서는 작은 HUD를 기본으로 사용하고 기체 중앙 시야를 비웁니다. 실제 가속·감속·러시·플로우 확정 기능을 유지합니다.

## 항로와 보상

- 한 생성 구간 안에서도 구조물 간격을 다르게 배치합니다. 속도가 높아지면 조종에 필요한 최소 간격을 우선하고 기존 도달 가능성·실제 충돌 검사를 유지합니다.
- 생성 구간 끝의 고정 여유를 125m에서 95m로 줄여 다음 구간 앞의 공백을 완화했습니다. 원본 고정 패턴의 여유는 유지합니다.
- 매 구조물마다 붙던 보상 링을 구간당 한 개로 줄였습니다. 도입부 학습 링은 세 개에서 두 개로 줄였고, 화면에는 가까운 링 두 개까지만 표시합니다. 구조물·코인·통과 판정은 계속 존재합니다.
- 항구·마을 등의 건물 수·선택·앞뒤 간격·좌우 위치·크기를 시드로 변화시킵니다. 같은 입력은 같은 항로를 재현합니다.
- 비행 고도에서 지형이 드문 연결부에는 절벽·빙주·암석을 보충합니다. 조종 범위 밖의 풍경이므로 추가 충돌을 만들지 않습니다.
- 기존 기록과 기체·코인을 보존합니다. 코스 판본을 갱신해 이전 배치의 개인 고스트가 새 경로와 섞이지 않게 합니다.

## 검증

변경과 관련된 테스트 19종을 통과했습니다. 기존 UI 검사에서 바뀐 무한 모드 버튼 문구를 반영한 뒤 해당 검사도 다시 통과했습니다. 이번 패치에서 전체 54종을 모두 재실행한 것은 아닙니다. [검증 결과](validation/release-9.1.0.json)

- `tests/v2/endless-rhythm.ts`: 787개 검사. 13개 테마 도달 가능성, 180초 지역 전환, 156개 생성 구간, 76가지 간격 조합, 156가지 건물 배치, 148개 비충돌 풍경 연결부 및 가까운 두 링의 실제 렌더 목록을 확인했습니다.
- 기존 충돌 판정을 사용한 자동 조종 검사: 무한 비행 66회가 각각 240초, 짧은 출격 12회가 각각 180초를 완료했습니다. 러시를 사용하는 여정 5회도 통과했습니다.
- 실제 정적 빌드의 브라우저 검사: 기본 무한 모드, 다른 모드 선택, 계기판 전환, 출격·입력·일시정지·종료·기록 저장을 확인했습니다. 844×390 및 736×320 터치 화면에서 주요 조작 버튼과 계기판의 겹침을 검사했습니다. 검사 중 JavaScript 오류 및 HTTP 실패는 없었습니다.
- TypeScript, 게임 ESLint, 프레임워크 빌드, GitHub Pages 경로의 정적 빌드가 통과했습니다. 기존 403개 모델·22종 기체·891개 애니메이션 클립을 유지합니다.

브라우저 검사는 Chromium 소프트웨어 GPU 환경에서 수행합니다. 실제 기기 FPS나 사람 대상 재미 평가를 의미하지 않습니다.
