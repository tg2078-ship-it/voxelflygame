# VOXEL AIRRUN 8.1.0

마을에 진입한 뒤 낮고 드문 구조물만 남던 항로와, 도장 메뉴에서 실물 기체가 흐려지던 문제를 개선했습니다.

- **항로와 난이도:** 표준·숙련의 첫 장애물과 후속 판단 간격을 줄였습니다. 고속 구간의 과도한 간격 확대를 줄이되 기체의 실제 조종 성능으로 도달 가능성을 계속 검사합니다. 테마별 종탑·암주·빌딩 등이 비행 고도까지 올라오는 선회 구간을 만듭니다. 기본 경로와 금빛 보상 경로를 모두 비워 둡니다.
- **마을과 배경:** 구간 길이에 따라 마을 군집 수가 늘어나며 건물의 비율을 유지하면서 크기를 키웁니다. 배경 오브젝트 제한 안에서 가까운 수목과 먼 능선을 고르게 배분하고, 먼 암벽의 실루엣을 강화합니다. 배경에는 충돌 판정을 추가하지 않습니다.
- **도장 작업실:** 패널의 배경 흐림이 뒤의 3D 기체까지 흐리던 문제를 수정했습니다. 반응형 실시간 기체 보기, 정면·측면·후면·위쪽 시점, 확대·축소·초기화, 기체 선택, 선택 도장의 명확한 표시와 구매·적용 버튼을 제공합니다. 미리보기만으로는 코인을 사용하지 않습니다.
- **UI와 로딩:** 메뉴 선택 상태·키보드 포커스·출격 버튼·카드·작업실을 정리했습니다. 로딩 항로와 진행 막대가 실제 준비율에 맞춰 움직이며 비행 조작 안내를 표시합니다. 이전 버전 문구를 정리하고 모션 감소 설정을 존중합니다.
- **표면·기록 수정:** 공항 섬의 흙과 잔디 표면이 거의 겹쳐 생기던 줄무늬를 줄이도록 간격을 확보했습니다. 코스 버전이 다른 과거 비행 잔상을 새 코스에 표시하지 않습니다. 기존 저장 기록은 유지합니다.

## 검증

- 타입 검사, 게임 린트, 프레임워크 빌드, GitHub Pages 하위 경로 정적 빌드.
- 절차 생성·난이도·필수 통과 경로·충돌·지형·출격·기록·UI 관련 회귀 검사 11개 묶음.
- 13개 테마의 새 구조물과 보상 경로를 실제 충돌 자료로 검사하는 `tests/v2/refinement.ts`: 6,153개 검사.
- 선택 경로의 실제 충돌 검사 `tests/v2/route-choice.ts`: 1,134개 검사.
- Chromium에서 실제 격납고·도장·출격·조작·종료·IndexedDB 기록 저장 검사. 브라우저 검사는 소프트웨어 GPU 환경이며 실제 사용자 하드웨어의 FPS나 재미를 입증하는 자료는 아닙니다.

원본 기체 22종, 모델 403개, 애니메이션 클립 891개를 유지합니다.
