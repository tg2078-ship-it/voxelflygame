# VOXEL AIRRUN 4.1

기존 403종 원본 모델과 22종 기체를 유지하면서 반복 코스, 프레임 지연, 크기가 튀는 LOD, 구간 사이 충돌과 터치 조작을 수정했습니다. 이번 버전에서 원본 GLB·텍스처·충돌 파일을 다시 만들지 않았습니다.

## 비행과 배치

- 아치·벽·횡단·다리 구간을 분리했습니다. 벽과 횡단 구간이 같은 아치를 재사용하지 않습니다.
- 테마별 아치와 다리를 순환하고, 원본 개구부가 기체보다 작으면 실제 구조물 위로 비행하도록 합니다. 통과용 아치의 균일 배율은 2.7 이하입니다.
- 첫 회피 선택을 읽을 수 있는 중앙 구조물을 추가했습니다. 장애물 개수의 무제한 증가는 사용하지 않습니다.
- 전체 381종 환경 모델을 순환하는 테마 덱을 유지하면서 좌우·전후 위치, 크기, 방향을 바꿨습니다. 기본 외곽 크기를 위치 계산에 반영해 구조물이 이동 범위 안에 배치되도록 조정합니다.
- 입구부터 출구까지 연속 경로와 움직이는 부품의 범위를 비웁니다. 수송기가 마지막 통과 지점 뒤에서 수집용 등대에 충돌하던 사례를 수정했습니다.

## 로딩과 렌더링

- 원본 모델의 서로 다른 LOD 경계와 접지 높이를 비교합니다. 맞지 않는 저해상도 버전은 호환되는 버전으로 대체합니다. 모델 형태가 바뀌는 상황을 줄이기 위한 정책이며 원본 파일 자체는 보존합니다.
- 가로 거리까지 포함해 표시 수준을 선택하고, 가까운 충돌 모델과 먼 배경을 구별합니다. 원본 형상 때문에 LOD 0을 사용해야 하는 먼 모델을 긴급 충돌 모델로 취급하지 않습니다.
- 지형 생성과 정적 모델 결합을 별도의 작업 스레드에서 처리합니다. 원본 디코더의 큰 버퍼 전체를 복제하는 대신 필요한 접근자의 범위만 복사해 소유권을 전달합니다.
- 작업 스레드를 사용할 수 없으면 기존 생성과 분할 결합 경로를 사용합니다. 가까운 모델의 결합을 기다리는 동안 원본 모델을 표시할 수 있습니다.
- 실제 애니메이션 컨트롤러와 PBR 재질을 유지하면서, 완전히 같은 불투명 부품을 기체별 인스턴스로 묶습니다. 스킨·모프·투명 부품은 제외하고 전단이 생기는 자세는 원래 렌더러로 처리합니다.
- 먼 작동부는 거리와 원본 그리기 비용에 따라 제한합니다. 가까운 움직이는 충돌 모델은 원래 시간과 위상으로 재생합니다.
- 지형 품질을 바꿀 때 기존 바닥을 새 지형이 도착할 때까지 유지합니다. 속도가 계속 증가해도 렌더링 범위는 품질별 1,800 / 2,600 / 3,600m로 제한합니다.
- 30 FPS 설정은 시각 처리도 30회로 제한합니다. 물리 처리는 60Hz로 유지합니다.
- 복제 중인 모델을 캐시 정리가 제거하지 않도록 참조를 먼저 확보하고, 중복 해제가 다른 인스턴스의 참조를 줄이지 않도록 수정했습니다.
- 출발 전 모델·지형·결합 작업을 기다리고 텍스처와 셰이더를 준비합니다. 진행률은 이 단계들을 표시합니다.

## 조작과 화면

- 조이스틱·가속·감속이 각 손가락을 추적합니다. 다른 손가락의 취소 이벤트가 조작을 끊지 않습니다.
- E는 터치 한 번 또는 키보드로 발동합니다. 한 판 한 번, 15초와 준비 중 상태 표시를 유지합니다.
- 작은 가로 화면에서는 계기판을 손가락 위로 옮기고, E 버튼의 터치 영역을 44px로 늘렸습니다. 아주 낮은 화면에서는 보조 정보를 줄입니다.
- 가속·감속의 눌림 표시와 발동 중 E 표시를 보강했습니다. 일시정지에서 돌아오면 비행 키 입력을 다시 받을 수 있도록 버튼 포커스를 해제합니다.

## CPU 장면 비교

동일한 seed 44171, HIGH, 80m/s, 6초 경로의 준비 완료 장면을 집계했습니다. 카메라 절두체 판정 전 월드 메시의 잠재적 기본 패스 횟수와 삼각형 수입니다. 그림자·물·효과·후처리를 포함하는 실제 GPU 드로우나 FPS가 아닙니다. 배치와 렌더링 정책을 함께 바꾼 버전 간 비교입니다.

## 검사

현재 검사 등록은 22개 세트입니다. 기본 20개 세트가 연속 실행에서 통과했고, 이후 변경의 영향을 받는 세트와 두 작업 스레드 세트를 다시 실행했습니다. 실행 결과는 `validation/game-tests-v4.1.log`에 저장합니다.

- 22종 기체 × 레벨 1·10·20: 66회 모두 240초 조종 비행.
- 381종 환경 모델: 8개 테마, 2개 seed, 2개 날개 폭의 32개 사례에서 전체 덱 배치.
- 애니메이션 정점 1,305,040개 비교: 최대 위치 오차 약 0.000000234m.
- 분할 결합 정점 223,877개 비교: 최대 위치 오차 약 0.00000249m.
- 실제 CPU 모델 작업 스레드: 큰 모델 네 종의 속성 값 19,182,846개 비교, 차이 0. 환경 381종과 교통 보조 4종 모두 재질 그룹과 삼각형 보존.
- 지형 762,060개 정점 비교와 실제 CPU 스레드 6개 사례: 같은 위치·법선·색 배열, 취소·실패 처리 확인.
- E 경로 352개 사례와 고속 스트레스 216개 사례: 실패 0, 구조물 안에서 시작한 사례 0.
- 30분 자원 수명 검사, 실기체 리그·연속 충돌·저장 데이터·UI 문서 구조 검사.

브라우저 조작 도구가 없는 환경에서 검증했습니다. WebGL 화면, 실제 브라우저 작업 스레드와 입력 이벤트, 모바일 화면 배치, 실기기 FPS 및 사람이 느끼는 재미는 직접 확인하지 못했습니다. CPU 작업 스레드의 전송과 반환값 검사는 실제 Node 스레드에서 수행했습니다.
