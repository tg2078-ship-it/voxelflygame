# AIRRUN 비행 모델 및 안정성 점검

## 기준선

React 격납고가 Zustand에 기체·난이도·시드를 저장한다. Three.js 렌더러가 비행 시뮬레이션을 만들고 입력을 1/60초 단위로 전달한다. 시뮬레이션은 항로 생성기, 충돌 형상, 기상, 보상 판정을 호출한다. 렌더러는 두 물리 프레임 사이의 자세를 보간하고 HUD와 오디오에 사건을 전달한다. 비행 결과는 검증을 거쳐 정산되고 IndexedDB에 기록된다. 브라우저 저장소 장애 시 Web Storage가 예비 저장소 역할을 한다.

| 항목 | 조사 결과 |
|---|---|
| 기준 난이도 | 여유·초보자·보통·숙련 4단계. 일반 Skyhawk 1레벨의 출발 속도는 초보자 144km/h, 보통 166km/h |
| 기본 속도 | 거리 함수에 기체 성능을 곱한다. 현재 순항 상한이 없으며 가속 열은 아직 시각 효과다 |
| 항로 | 13개 테마. 보통의 기준 간격 166m, 초보자 185m. 실제 구간 간격에는 테마, 난수, 기체 조종성, 속도 보정이 적용된다 |
| 치명타 | 지면·대형 구조물은 즉시 추락할 수 있다. 작은 구조물 정면 충돌은 속도·방패를 검사한다. 번개는 폭풍, 시드, 비행 시간, 횡속도 조건을 함께 만족해야 피해를 준다 |
| 보상 | 근접 회피 기본 120점, 위험 경로 300점, 풍경 8종 600점. 보통 이상에는 구조물 3연속 릴레이 450점 또는 750점이 있다 |
| 성장 | 1레벨 기준 각 강화 단계의 증가량은 순항 3.1%, 가속 7.5%, 조종 5.5%, 내구도 8.5%. 20레벨 Skyhawk 조종 계수는 2.045, 1레벨 Falcon은 1.545 |
| 음악 | 스트림 2개, 환경 루프 7개, 사건 효과음은 신시사이저. 재생 승인과 실제 파일 읽기·디코드 실패는 다른 경로를 이용한다 |
| 테스트 | 첫 실행의 타입 검사는 통과. 전체 린트는 오류 88개, 경고 3,766개. 당시 npm test 별칭이 없었다. 게임용 검사에는 난이도 버튼 개수, 강화 내구도, 렌더러 대역에서 이전 버전 기대값 3개가 남아 있었다 |

다음 수치는 1레벨 Skyhawk·보통·중립 스로틀에서 거리 함수를 평가한 값이다. 마지막 열은 일정한 166m 간격을 가정한 비교용 수치다.

## 기체 제작과 검사

Skyhawk를 제외한 21대를 새로운 메시로 제작했다. 각 기체의 두 거리별 GLB를 생성하는 원본은 scripts/build-flight-fleet.mjs에 있다. 원거리 모델은 동체 리브, 바퀴 허브와 세부 마킹을 줄인다. 각 기체의 기존 ID와 비행 충돌 판정에 쓰는 전장·전폭을 유지한다. 선택 화면, 도장실, 무한 비행은 같은 모델 라이브러리를 사용한다. 격납고 카드의 정지화상은 새 모델을 WebGL로 렌더링한 결과다.

flight-fleet 검사는 42개 GLB를 디코드하고, 원래 기체 크기 대비 각 축 오차 1mm 미만인지, 모든 애니메이션 트랙에 실제 대상 노드가 있는지 검사한다. 회전익·프로펠러는 자율 재생하며 고정익의 조종면과 일부 기종의 착륙장치는 비행 상태를 따른다.

## 안정성 변경 및 검사 방법

- 비행 중 버튼에 포커스가 남아도 Space를 감속으로 처리한다. 일반 메뉴의 키보드 버튼 조작은 유지한다.
- 일시정지와 재개 요청을 반복해도 재개 카운트다운이 튀지 않는다. 창이 숨겨지거나 포커스를 잃으면 진행 중인 카운트다운을 취소한다.
- 조종사 프로필이 손상되면 복구 가능한 기체, 코인, 강화 단계와 유효 기록을 복원한다. 교체 전 원본을 최대 세 개까지 보관한다. 설정의 이전 저장 원본 내보내기에서 최근 원본을 받을 수 있다.
- 수동 가져오기는 결과를 미리 보여주고 확인 후 복원한다. 같은 파일을 다시 선택할 수 있으며, 다운로드 URL은 1초 뒤 해제한다.
- 폭풍 번개 예고는 필요한 횡속도를 한국어·영어로 표시한다. 누락되거나 해독할 수 없는 오디오는 설정에 파일명을 표시한다.
- 실시간 조종석을 별도 구독하는 React 컴포넌트로 분리했다. 비행 중 매 HUD 갱신마다 격납고를 포함한 화면 전체를 다시 계산하던 경로를 없앴다.

전체 린트를 위해 정적 번들 출력은 검사 대상에서 제외하고 테스트 대역과 검사 보고서의 타입을 정리했다. 기존 규칙은 유지했다. 이후 구형 엔진 네 파일의 린트 오류 9개를 수정했다. 전체 린트는 오류 0개와 기존 경고 36개, 타입 검사와 구형 엔진 테스트는 종료 코드 0이다. 게임 회귀 테스트 59개 묶음이 통과했다. 이 단계에서 장거리 속도 상한과 부스트 과열 잠금, 회피 롤, 두 번째 기회는 플레이 규칙에 반영되지 않았다.

## 직접 플레이할 항목

1. 기체 선택에서 복엽기, 델타기, 구조 헬기를 차례로 고르고 뒤쪽과 측면 실루엣을 비교한다.
2. 보유 기체의 도장을 바꾼 뒤 출격하고 좌우 선회 시 조종면과 도장 색을 확인한다.
3. 조종석의 상세 계기판을 클릭한 직후 Space로 감속한다.
4. 일시정지·재개 도중 반복 입력, 다른 탭으로 전환 및 복귀를 시도한다.
5. 초보자와 보통에서 같은 기체로 첫 구간과 두 번째 지역을 각각 비행하고, 급선회까지 남는 시간과 구조물 식별성을 비교한다.

실제 GPU·휴대전화 기종별 FPS, 장시간 플레이 피로도와 난이도 선호도는 사람의 기기에서 확인할 항목이다.
