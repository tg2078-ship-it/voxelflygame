# VOXEL AIRRUN 9.0.0 · Three-minute Sorties / Edition12

9.0.0은 한 출격 안에서 펼쳐지는 네 지역의 여정, 정밀 비행으로 충전하는 러시, 새 비행 계기판·결과 화면과 격납고 개선을 제공합니다. [변경·검증 기록](docs/RELEASE-9.0.0.md)

[게임 플레이](https://tg2078-ship-it.github.io/voxelflygame/)

8.0은 3분 완주형 출격, 선택하는 비행 목표 3종, 같은 항로 재도전과 개인 고스트를 추가합니다. 절차 생성은 출격의 시작·고조·재정비·최종 도전·귀환 흐름을 만들며, 실제 형상을 검사한 정밀 경로와 3D 안내 표식으로 다음 행동을 보여 줍니다. 충돌 처리와 화면을 가리던 성공 효과도 수정했습니다. 22종 기체·13개 테마·원본 403종, 첫 구간부터의 절차 생성·세 난이도·데일리 항로와 기존 저장을 유지합니다. 변경과 검증, 남은 출시 검증 범위는 [RELEASE-8.0.md](docs/RELEASE-8.0.md)에 있습니다.

## 달라진 비행

- **네 지역의 여정:** 해안 → 마을 → 도시 → 다섯 종류 중 시드로 선택한 마지막 지역을 비행합니다. 실제 도달한 지역과 비행 시간은 결과 화면에 남습니다.
- **정밀 비행으로 얻는 러시:** 링과 경로 통과로 충전한 뒤 Q 또는 화면 버튼으로 5초 가속·코인 자석을 발동합니다. 감속으로 회피할 수 있고, 충돌 판정은 유지됩니다.
- **3분 출격과 선택 목표:** 정밀 통과·수동 가속·근접 회피 중 하나를 선택하고 세 단계 보상과 완주를 노립니다. 달성 목표는 최대 1,050점, 완주는 1,200점이며 실제 점수 내역에 반영됩니다.
- **같은 항로 재대결:** 시드·기체·강화 단계·난이도·목표를 유지해 다시 출격합니다. E 없이 완주한 같은 조건의 최고 기록이 있으면 로컬 고스트와 앞섬/뒤처짐 거리를 표시합니다.
- **비행 작전 8종:** 통과 경로 연결, 링, 중심 통과, 저공, 가속, 코인, 근접·협문, 무피격 통과를 실제 비행 행동으로 완료합니다. 작전·정밀 보상과 확정한 플로우 보너스가 실제 점수와 정산에 반영됩니다.
- **플로우 확정과 평가:** F 또는 화면 버튼으로 미정산 추가 보너스를 확보하면 체인과 배율이 다시 시작됩니다. 피격·8초 단절은 미정산분만 잃게 합니다. 연속 행동으로 배율을 높이고, 종료 화면에서 작전 완수·정밀 통과·최고 연속 기록과 BRONZE / SILVER / GOLD / ACE 평가를 확인합니다.
- **오늘의 항로:** 뉴욕 시간의 날짜로 고정 시드를 생성합니다. 표준 난이도를 사용하며 일반 비행과 E 사용 기록을 구분해 기기에 저장합니다. 온라인 순위표는 제공하지 않습니다.
- **세 가지 난이도:** 여유·표준·숙련은 속도 배율 0.88× / 1.00× / 1.12×와 행동 간격·경로 변화량을 함께 바꿉니다. 여유에서도 충돌과 보상은 유지됩니다.
- **화면과 풍경:** 공항 바닥, 격납고 대시보드, 비행 HUD, 로딩·조종사 카드·보상 화면을 개편했습니다. 구역별 건물·작업 시설을 조합하고 해안의 섬·절벽, 하늘 그라데이션·구름·수면 표현을 다듬었습니다.

## 모델과 기존 기능

Edition12의 403종 모델, 4단계 시각 LOD 1,612개, 최고 단계의 애니메이션 모델 271종·클립 891개와 원본 충돌 자료를 유지합니다. 6.0에서 원본 모델 파일을 교체하거나 저해상도 대체 모델로 바꾸지 않았습니다. 모델 사전에서는 실제 3D 모델의 회전·확대·동작 재생이 가능합니다.

5.0.2의 모델 병합·다운로드 재시도·품질 전환·입력 해제·저장 복구 수정도 유지합니다. 세부 내용은 [5.0.2 기록](docs/RELEASE-5.0.2.md), 원본 Edition12 가져오기와 배포 LOD 정책은 [5.0 기록](docs/RELEASE-5.0.md)을 참고하세요. 배포용 프로필은 모든 기체와 주요 랜드마크에 네이티브 LOD0을, 그 밖의 일부 환경에 네이티브 LOD1을 근거리 최고 단계로 선택합니다. 소스의 `public/models`에는 전체 원본 LOD0을 보존합니다.

## 로컬 실행

Node.js 22.13 이상과 pnpm 11.25.0을 사용합니다. 프로젝트 루트에서 실행한 뒤 터미널에 표시된 주소를 엽니다.

```sh
npx --yes pnpm@11.25.0 install --frozen-lockfile
npm run dev
```

Linux/WSL의 프로젝트 전용 설치 경로를 사용하려면 `npm run install:ci`로 설치할 수 있습니다. 배포용 빌드는 `npm run build`입니다. 게임 코드는 `app/airrun`, 모델은 `public/models`, 자동 검사는 `tests/v2`에 있습니다.

```sh
npm run typecheck
npm run lint:game
npm run test:game
npm run build
```

## 검증 범위

자동 검사는 실제 모델과 충돌 자료를 사용하는 경로·러시·난이도·저장 검증을 포함합니다. Chromium에서는 격납고·도장·출격·일시정지·결과 저장을 확인합니다. 버전별 결과는 각 릴리스 문서에 기록합니다. 브라우저 검증 환경은 소프트웨어 GPU이며 실제 PC·모바일 GPU의 FPS·발열·장시간 플레이와 사람 대상 재미 평가는 별도 검증이 필요합니다.
