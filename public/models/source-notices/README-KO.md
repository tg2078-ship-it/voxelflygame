# VOXEL-AIRRUN / Edition 9

총 403종(항공기 22, 월드 381), 네이티브 애니메이션 보유 203종입니다. 파일명 400은 기존 다운로드의 이름을 유지한 것입니다.

이번 에디션은 기준 이미지의 8종 기체를 기존 제작용 loft/voxel 라이브러리에서 재구성·보강하고, 가동 격납고·등대·풍차 3종을 새로 추가했습니다. 나머지 392종의 형상은 Edition 8에서 유지합니다. 403종 전체를 새로 만든 것으로 표시하지 않습니다.

## 가장 빠른 실행

별도 Playable-Kit ZIP을 풀고 `AIRRUN-Flight-Workshop.html`을 브라우저에서 여세요. 서버·npm·Python 설치 없이 31종 내장 샘플을 볼 수 있습니다. 최신 Chromium 계열 브라우저에서 실제 WebGL2 실행과 다운로드를 검사했습니다.

전체 모델 ZIP은 새 폴더에 압축을 풀고, 작업실의 **전체 에셋 폴더 연결**에서 `catalog.json`과 `themes`가 들어 있는 폴더를 선택합니다. 그러면 403종을 열 수 있습니다. 테마별 ZIP과 Hero-Assets ZIP도 각각 독립적인 카탈로그를 포함합니다. 모델 파일은 외부로 전송하지 않습니다.

## 게임에 가져오기

| 파일 | 용도 |
|---|---|
| `_lod0.glb` | 가까이 보는 기체·랜드마크 |
| `_lod1.glb` | 게임용 시각 모델 |
| `_lod2.glb` | 원거리 시각 모델 |
| `_collision.glb` | 단순화된 충돌 표면 |
| `_collision_detail.glb` | 근접 모델의 정밀 충돌 표면 |
| `motion.json` | 네이티브 클립·자동 재생 목록 |
| `collision.json` | 충돌 형상과 바인딩 정보 |
| `metadata.json` | 치수·LOD 통계·배치 정보 |

단위는 m, 위쪽 +Y, 전방 -Z입니다. 시각 모델과 충돌 모델에 같은 루트 변환과 애니메이션 시간을 적용합니다. 이번 11종의 정밀 충돌 표면은 최종 LOD0의 모든 삼각형 정점과 일치하는 것을 독립적으로 검사했습니다. 새 11종의 단순 충돌 표면은 LOD2에서 추출한 비볼록 삼각형 표면입니다. 강체 엔진용 convex hull과는 다르므로 사용하는 엔진에 맞게 정적 메시/kinematic 질의/별도 convex 분해를 선택합니다.

8종 기체는 프로펠러만 기본 재생하고 조종면과 기어를 입력으로 제어합니다. `Airrun.GameAsset`은 시각·충돌의 같은 네이티브 컨트롤러에 입력을 적용합니다. `playClips()`로 수동 클립도 직접 재생할 수 있습니다.

`placement.ground_rotation_x_rad`가 있는 꼬리바퀴 기체는 지상 배치할 때 해당 X 회전을 먼저 적용하고, 실제 바운딩 박스 하단을 지면에 맞춥니다. 비행 중에는 지상 각도를 해제합니다.

## 실행 예제

WASD 또는 방향키로 이동, Shift로 가속, Space로 감속, H로 히트박스 표시, R로 재시작합니다. 가속 횟수 제한은 없습니다. 모바일 가로 화면에는 터치 버튼이 있습니다. 비행 예제는 1/120초 고정 스텝을 사용하고, 기체의 여러 표면 근처 점에 대한 구체 이동 검사로 월드 접촉을 확인해 비행을 멈춥니다. 실기체 비행 시뮬레이터나 완성 게임은 아닙니다.

작업실의 `GLB 저장`은 현재 시각 LOD 한 파일을 저장합니다. 전체 파일과 동작·충돌 메타데이터가 필요하면 ZIP을 사용하세요.

## 검증

`VALIDATION.json`에 실행 결과를 구분해 기록했습니다. 2,015개 GLB의 바이너리·내장 이미지, 실제 Three.js GLTFLoader 임포트, 네이티브 애니메이션, LOD/충돌 변환, 기계 연결점, 새 11종 전체 정밀 표면, 8종 입력 바인딩, 실제 문의 통과/차단과 풍차 회전 충돌을 검사했습니다. 브라우저에서는 오프라인 로딩·403종 폴더 선택·실제 GLB 다운로드·키 입력 비행·충돌 정지·가로 화면 터치 버튼을 검사했습니다.

브라우저 실행 환경은 SwiftShader 소프트웨어 GPU였습니다. 출력 영상의 12fps는 게임 성능 수치가 아닙니다. 사용자의 실제 PC/모바일 GPU 성능, Unity/Unreal/Godot 프로젝트 임포트는 별도 검증 대상입니다.

## 제작 소스

Authoring-Source ZIP에는 Edition9 수정 소스와 이에 필요한 기존 제작 라이브러리·Three.js MIT 소스가 있습니다. 새 11종을 재생성할 수 있습니다. 남은 392종은 완성 모델 팩을 입력으로 유지합니다. 소스 빌드에는 Python 3.12, NumPy, SciPy, Pillow와 Node가 필요하고, 브라우저 검증에는 Playwright/Chromium, 영상 조합에는 FFmpeg가 필요합니다. 에셋 사용에는 이 제작 환경이 필요 없습니다.
